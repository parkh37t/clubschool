# Wylie AX Office — 설치형 앱(Windows)

> English: [README.en.md](README.en.md)

PowerShell 없이 더블클릭으로 쓰는 Wylie AX Office. 앱이 오케스트레이터 서버(`server/`)를 내부에서 띄우고,
창에서 가상 사무실 화면을 엽니다. 화면 구조와 운영 방식은 Munder Difflin을 따랐습니다(코드는 가져오지 않음).

| 자리 | 내용 |
| --- | --- |
| 위 | 앱 이름 · 모드 · 동시 작업 · 시계 · **언어(한국어 / EN)** |
| 왼쪽 | 픽셀 사무실(책상을 누르면 그 에이전트 선택). 추가한 인원은 아래쪽 확장 구역에 앉음 |
| 오른쪽 | 커맨드 센터 — 작업 · 승인 · 질문 · 기억 · 활동 · 스킬 · 터미널 · 모니터 · 예약 · 관계도 탭, 대기열, 입력창 |
| 하단 | 에이전트 카드 — 팀장 + 12인 + 추가 인원(상태·지금 하는 작업·사용량·서킷 브레이커), **＋ 인원 추가** |

## 설치

1. `release/Wylie-AX-Office-Setup-<버전>.exe` 를 실행합니다. 설치 프로그램은 Windows 언어가 한국어면 한국어, 아니면 영어로 뜹니다.
2. **Windows SmartScreen 경고**가 뜰 수 있습니다. 코드 서명을 하지 않은 설치 파일이라서입니다.
   [추가 정보] → [실행]을 누르면 설치가 진행됩니다.
3. 사용자 계정에 설치되므로 관리자 권한이 필요 없습니다(기본 위치 `%LOCALAPPDATA%\Programs\Wylie AX Office`).
4. 시작 메뉴·바탕 화면의 **Wylie AX Office** 로 실행합니다.

## 쓰기 전에 — Claude 로그인

앱은 이 PC의 Claude 데스크톱 앱에 들어 있는 Claude Code(`claude.exe`)를 불러 일합니다(API 키 없음, 구독 사용량).
로그인이 풀려 있으면 화면 위에 배너가 뜹니다. **[로그인]** 을 누르면 새 PowerShell 창이 열리고,
브라우저에서 승인한 뒤 화면에 나온 코드를 그 창에 붙여 넣으면 됩니다. 확인되면 배너가 사라집니다.

Claude 데스크톱 앱이 업데이트되면 내장 Claude Code 도 새 버전으로 바뀌고 **로그인이 풀릴 수 있습니다.** 배너가 다시 뜨면 같은 방법으로 로그인하세요.
AX Office 는 바뀐 Claude Code 를 다시 시작하지 않아도 찾아 씁니다. 로그인이 풀린 동안 보낸 브리핑은 시작하지 않고 대기열에 '실패'와 안내를 남깁니다.

## 일 맡기기

- **메시지**(기본): 입력창에 쓰고 **Enter** 로 보냅니다(줄바꿈은 Shift+Enter, 한글 조합 중 Enter 는 보내지 않음). 대기열에 들어가 팀장 상주 세션이 한 건씩 답합니다.
  진행 상황을 묻거나, "결과: …"를 함께 적어 일을 맡기면 팀장이 브리핑으로 정리해 대기열에 넣습니다.
- **브리핑 양식**: 결과·맥락·제약·질문 기준을 직접 채워 **Ctrl+Enter** 로 대기열에 넣습니다(과제명 칸의 Enter 는 결과 칸으로). 파일을 끌어다 놓아 첨부할 수 있습니다.
- **폴더 첨부**: [폴더]로 폴더를 고르거나 상자에 폴더를 끌어다 놓으면, 안의 문서만 골라 폴더 구조 그대로 올립니다(최대 40개). 실행 파일·숨김 폴더는 건너뜁니다.
- **음성 입력**: 앱 안에서는 브라우저 음성 인식이 동작하지 않으므로 Windows 음성 입력(**Win+H**)을 쓰세요.
- 브리핑은 한 번에 하나씩 돌고 나머지는 차례를 기다립니다. 아직 시작하지 않은 항목은 대기열에서 취소할 수 있습니다.
- **제안서**: 템플릿 탭의 '제안서 — 전체 프로세스'를 쓰거나 결과 줄에 제안서를 적으면 8단계(조사 → RFP 분석·Go/No-Go → 전략·목차 →
  UX 섹션 → KPI → 장표 구성안 → 본문 → 검수)로 나뉩니다. Go/No-Go 와 견적 수치는 승인 탭에서 재하가 결정해야 다음으로 넘어갑니다.

## 사무실 화면

- 가로로 넓은 평면도: 부서 방 6개, 사장실·라운지·팀장실·서버룸, 아래 줄에 회의실(12석)·포커스룸(통화 부스 2)·자료실·확장 구역(추가 인원 6석).
- 일이 시작되면 담당이 회의실로 모이고, 쉬는 사람은 라운지·자료실·통화 부스에 다녀옵니다. 팀장은 가끔 일하는 사람의 방을 돌아봅니다.
- 아래 에이전트 바는 기본으로 접힌 칩 한 줄이고, 오른쪽 끝 버튼으로 카드 보기로 펼칩니다.

## 설정

상단 바의 **설정**에서 바꿉니다. 값은 `hive\settings.json` 에 남습니다.

- **산출물 저장 위치**: 지금 폴더를 열거나, 새 폴더를 [폴더 고르기]로 골라 바꿉니다. '기존 산출물도 복사'를 켜면 지금 폴더 내용을 새 폴더로 복사합니다(덮어쓰지 않고 예전 폴더는 그대로). 브리핑이 도는 중에는 바꿀 수 없습니다. 트레이의 '산출물 폴더'도 바뀐 위치를 엽니다.
- **사용량 한도**: 작업당·에이전트 하루 사용 토큰 한도(천 토큰 단위로 입력).
- **동작**: QA 반려 시 1회 자동 보완, 동시에 도는 작업 수(1~3, 새 브리핑부터).
- **기획 에이전트 패키지**: 규격·린트·검증·골든·팩 템플릿이 있는 폴더를 연결하면 화면설계 브리핑이 표준 기획 프로세스로 돌고, **기획** 탭에서 팩·화면을 봅니다.
- **언어 · 환경**(Claude Code 설치·로그인) · **작업 기록(hive) 위치**.

작업 탭의 산출물 카드에서 **[열기] [Word] [폴더]** 로 파일을 바로 엽니다.

## 탭

위 줄에 자주 쓰는 여섯 탭(작업·기획·승인·질문·대화·터미널)이 건수와 함께 보이고, 나머지(모니터·템플릿·예약·기억·활동·관계도·스킬)는 **더보기**에 있습니다.

| 탭 | 하는 일 |
| --- | --- |
| 기획 | 프로젝트 팩(SSOT 5계층 상태)·화면 레지스트리·린트·검증, [보기]로 2단 화면설계서(좌 화면·우 사양)를 앱 안에서 엽니다 |
| 작업 | 이번 브리핑의 진행률·사용 비용과 작업을 상태별로 묶어 보여 줍니다(승인 대기·진행이 위, 완료는 접힘). 산출물 판정, [열기]·[Word]·[폴더] |
| 대화 | 팀장·에이전트·재하가 주고받은 메시지를 메신저처럼(최신이 위) |
| 템플릿 | 자주 쓰는 브리핑 — 기본 6개(RFP 검토, 제안서 전체 프로세스, 주간 보고, 회의록, 벤치마킹, 화면설계)와 내가 저장한 것. [이 템플릿으로 쓰기]는 입력창을 채우기만 합니다 |
| 승인 | 재하 결정이 필요한 것 — 외부 발송·실제 비용(결제)·삭제·범위 변경·수치 확정, **사용 토큰 한도 초과**, **서킷 브레이커 재개**. 행위자·사유 필수 |
| 질문 | 팀장·에이전트가 재하에게 물은 것. 답하면 팀장은 바로, 에이전트는 다음 작업 때 읽습니다 |
| 기억 · 활동 · 스킬 | 에이전트별 기억 파일, 이벤트 기록, 쓸 수 있는 스킬 |
| 터미널 | 책상별 **실시간 기록**(시작·글·도구·결과·QA·완료). **[터미널 열기]** 는 그 사람의 페르소나를 붙인 대화형 Claude Code 를 엽니다 |
| 모니터 | 사용 토큰(합계·오늘·네 갈래·최근 7일·에이전트별 하루 한도 대비·작업별), 토큰 한도 설정, 서킷 브레이커 초기화 |
| 예약 | 정해진 시각에 브리핑 자동 실행(매주 요일·매일·한 번). 켜기·끄기, 지금 실행, 삭제. **앱이 켜져 있을 때만** 돌고, 꺼져 있던 동안의 예약은 '놓침'으로 남깁니다 |
| 관계도 | 브리핑 하나의 작업 선후관계와 진행 상태 그래프. 지난 브리핑도 골라 볼 수 있고, 노드를 누르면 담당자가 선택됩니다 |

## 사용량 안전장치

이 앱은 PC 에 로그인된 Claude 구독으로 돕니다. 쓴 양은 금액이 아니라 **사용 토큰**으로 셉니다(결제되지 않음).
사용 토큰 = 입력 + 캐시 생성 + 출력 + 캐시 읽기÷10 — 캐시에서 다시 읽은 토큰은 훨씬 가볍게 쳐져서 1/10 로 셉니다.

- **작업당 한도**(기본 40만 토큰, 기획 ②·③ 단계는 80만): 넘으면 그 작업이 멈추고 '사용량' 승인 카드가 뜹니다. 승인하면 한도를 두 배로 올려 이어서, 반려하면 보류.
- **하루 한도**(에이전트 1명, 기본 120만 토큰): 80%면 제한(턴·한도 절반), 100%면 중지.
- **서킷 브레이커**: 연속 문제 1회 조정 → 2회 제한 → 3회 중지. 중지된 사람에게 작업이 가면 '재개' 승인 카드가 뜹니다.
- 모니터 탭에 네 갈래(입력·캐시 생성·캐시 읽기·출력)가 보입니다. API 단가로 환산한 금액은 각주의 참고값일 뿐 청구되지 않습니다.

## 인원 추가

하단 **＋ 인원 추가** → 역할 템플릿 12종(일정·품질·문서·리서치·카피·콘텐츠·데이터 엔지니어링·보안·모바일·접근성·모션·고객 지원) 중 고르고
이름(한·영)을 정해 추가합니다. 최대 6명. 팀장 명단에 들어가 다음 브리핑부터 배정받습니다. 진행·대기 작업이 없을 때만 뺄 수 있습니다.

## 언어

화면 오른쪽 위 **한국어 / EN** 으로 바꿉니다. 화면·트레이 메뉴·알림이 함께 바뀌고, 영어로 두면 팀장과 에이전트에게 영어로 쓰라고 덧붙입니다.
작업 제목·산출물처럼 이미 만들어진 내용은 번역하지 않습니다. 설정은 `hive\settings.json` 에 남습니다.

## 창·트레이

- 창을 닫아도 **트레이에서 계속 실행**됩니다(진행 중인 작업도 계속 돕니다).
- 트레이 아이콘 메뉴: 열기 / 산출물 폴더 열기 / Windows 시작 시 실행(켜기·끄기) / **종료**
- **종료**를 누르면 서버와 claude 자식 프로세스(대화형 터미널 포함)를 모두 정리하고 끝납니다. 진행 중이던 작업은 다음 실행 때 '보류'로 닫힙니다.
- 이미 실행 중일 때 다시 실행하면 새로 뜨지 않고 기존 창이 앞으로 옵니다.
- Windows 시작 시 실행을 켜면 로그인할 때 창 없이 트레이로만 뜹니다.

## 동작 방식

- 서버는 Electron 내장 Node 로 돌고(`ELECTRON_RUN_AS_NODE=1`), `127.0.0.1` 에만 바인딩합니다. 포트는 8787(사용 중이면 8788~8799).
- 실행 모드는 `claude_code` 입니다. 시험할 때는 환경 변수로 바꿀 수 있습니다: `OFFICE_MODE=mock`,
  `OFFICE_HIVE_DIR`, `OFFICE_DELIVERABLES_DIR`(데이터 위치), `OFFICE_CONCURRENCY`(동시 작업, 기본 2·최대 3).
- 대화형 터미널은 node-pty(`@lydell/node-pty`, Windows ConPTY)로 열고 WebSocket 으로 화면과 주고받습니다. 이 PC 화면에서만 열립니다.
- 설치본에는 live(Agent SDK) 모드 의존성을 넣지 않았습니다(260MB). live 모드는 저장소에서 서버를 직접 띄워 씁니다.

## 개발·빌드 (저장소 루트에서)

```bash
npm install
npm run desktop:dev     # 화면 빌드 후 개발 실행(Electron 창)
npm run desktop:build   # 화면 빌드 후 설치 파일 → release/
npm run desktop:icon    # 아이콘 다시 만들기(desktop/scripts/make-icon.mjs)
```

- 설치 파일에 들어가는 것: `desktop/`(main 프로세스·아이콘), `server/`(hive 데이터·live 의존성 제외), `dist/`, `.claude/agents`, `.claude/skills`.
  빌드하는 PC의 `.claude/skills` 에 사내 스킬이 있으면 그것도 들어가므로, 설치 파일을 외부에 배포하지 않습니다.
- `release/` 는 커밋하지 않습니다.

## 지우기

설정 → 앱 → Wylie AX Office → 제거. `문서\Wylie AX Office` 의 작업 기록·산출물은 남습니다(필요 없으면 직접 지움).
