# Wylie AX Office — 설치형 앱(Windows)

> English: [README.en.md](README.en.md)

PowerShell 없이 더블클릭으로 쓰는 Wylie AX Office. 앱이 오케스트레이터 서버(`server/`)를 내부에서 띄우고,
창에서 가상 사무실 화면을 엽니다. 화면 구조와 운영 방식은 Munder Difflin을 따랐습니다(코드는 가져오지 않음).

| 자리 | 내용 |
| --- | --- |
| 위 | 앱 이름 · 모드 · 동시 작업 · 시계 · **언어(한국어 / EN)** |
| 왼쪽 | 픽셀 사무실(책상을 누르면 그 에이전트 선택). 추가한 인원은 아래쪽 확장 구역에 앉음 |
| 오른쪽 | 커맨드 센터 — 작업 · 승인 · 질문 · 기억 · 활동 · 스킬 · 터미널 · 모니터 탭, 대기열, 입력창 |
| 하단 | 에이전트 카드 — 팀장 + 12인 + 추가 인원(상태·지금 하는 작업·사용량·서킷 브레이커), **＋ 인원 추가** |

## 설치

1. `release/Wylie-AX-Office-Setup-<버전>.exe` 를 실행합니다. 설치 프로그램은 Windows 언어가 한국어면 한국어, 아니면 영어로 뜹니다.
2. **Windows SmartScreen 경고**가 뜰 수 있습니다. 코드 서명을 하지 않은 설치 파일이라서입니다.
   [추가 정보] → [실행]을 누르면 설치가 진행됩니다.
3. 사용자 계정에 설치되므로 관리자 권한이 필요 없습니다(기본 위치 `%LOCALAPPDATA%\Programs\Wylie AX Office`).
4. 시작 메뉴·바탕 화면의 **Wylie AX Office** 로 실행합니다.

## 쓰기 전에 — Claude 로그인

앱은 이 PC의 Claude 데스크톱 앱에 들어 있는 Claude Code(`claude.exe`)를 불러 일합니다(API 키 없음, 구독 사용량).
로그인이 풀려 있으면 화면 위에 배너가 뜹니다. **[로그인]** 을 누르면 새 PowerShell 창이 열리고,
브라우저에서 승인한 뒤 화면에 나온 코드를 그 창에 붙여 넣으면 됩니다. 확인되면 배너가 사라집니다.

## 일 맡기기

- **메시지**(기본): 입력창에 쓰고 Ctrl+Enter. 대기열에 들어가 팀장 상주 세션이 한 건씩 답합니다.
  진행 상황을 묻거나, "결과: …"를 함께 적어 일을 맡기면 팀장이 브리핑으로 정리해 대기열에 넣습니다.
- **브리핑 양식**: 결과·맥락·제약·질문 기준을 직접 채워 바로 대기열에 넣습니다. 파일을 끌어다 놓아 첨부할 수 있습니다.
- 브리핑은 한 번에 하나씩 돌고 나머지는 차례를 기다립니다. 아직 시작하지 않은 항목은 대기열에서 취소할 수 있습니다.

## 탭

| 탭 | 하는 일 |
| --- | --- |
| 작업 | 이번 브리핑의 작업과 상태(대기·진행·검수·승인대기·완료·보류·실패), 산출물 판정 |
| 승인 | 재하 결정이 필요한 것 — 외부 발송·비용·삭제·범위 변경·수치 확정, **비용 상한 초과**, **서킷 브레이커 재개**. 행위자·사유 필수 |
| 질문 | 팀장·에이전트가 재하에게 물은 것. 답하면 팀장은 바로, 에이전트는 다음 작업 때 읽습니다 |
| 기억 · 활동 · 스킬 | 에이전트별 기억 파일, 이벤트 기록, 쓸 수 있는 스킬 |
| 터미널 | 책상별 **실시간 기록**(시작·글·도구·결과·QA·완료). **[터미널 열기]** 는 그 사람의 페르소나를 붙인 대화형 Claude Code 를 엽니다 |
| 모니터 | 사용량(합계·오늘·최근 7일·에이전트별 하루 예산 대비·작업별), 작업당 상한과 하루 예산 설정, 서킷 브레이커 초기화 |

## 비용 안전장치

- **작업당 상한**(기본 $2): 넘으면 그 작업이 멈추고 승인 카드가 뜹니다. 승인하면 상한을 두 배로 올려 이어서, 반려하면 보류.
- **하루 예산**(에이전트 1명, 기본 $5): 80%면 제한(턴·상한 절반), 100%면 중지.
- **서킷 브레이커**: 연속 문제 1회 조정 → 2회 제한 → 3회 중지. 중지된 사람에게 작업이 가면 '재개' 승인 카드가 뜹니다.
- 금액은 Claude Code 가 알려 주는 추정치이며 청구서가 아닙니다.

## 인원 추가

하단 **＋ 인원 추가** → 역할 템플릿 12종(일정·품질·문서·리서치·카피·콘텐츠·데이터 엔지니어링·보안·모바일·접근성·모션·고객 지원) 중 고르고
이름(한·영)을 정해 추가합니다. 최대 6명. 팀장 명단에 들어가 다음 브리핑부터 배정받습니다. 진행·대기 작업이 없을 때만 뺄 수 있습니다.

## 언어

화면 오른쪽 위 **한국어 / EN** 으로 바꿉니다. 화면·트레이 메뉴·알림이 함께 바뀌고, 영어로 두면 팀장과 에이전트에게 영어로 쓰라고 덧붙입니다.
작업 제목·산출물처럼 이미 만들어진 내용은 번역하지 않습니다. 설정은 `hive\settings.json` 에 남습니다.

## 창·트레이

- 창을 닫아도 **트레이에서 계속 실행**됩니다(진행 중인 작업도 계속 돕니다).
- 트레이 아이콘 메뉴: 열기 / 산출물 폴더 열기 / Windows 시작 시 실행(켜기·끄기) / **종료**
- **종료**를 누르면 서버와 claude 자식 프로세스(대화형 터미널 포함)를 모두 정리하고 끝납니다. 진행 중이던 작업은 다음 실행 때 '보류'로 닫힙니다.
- 이미 실행 중일 때 다시 실행하면 새로 뜨지 않고 기존 창이 앞으로 옵니다.
- Windows 시작 시 실행을 켜면 로그인할 때 창 없이 트레이로만 뜹니다.

## 데이터 위치

설치 폴더에는 쓰지 않습니다(쓰기 권한이 없고 업데이트 때 지워짐).

| --- | --- |
| 작업 원장·승인·메일함·기억·이벤트·대기열·질문·설정(hive) | `문서\Wylie AX Office\hive` |

## 동작 방식

- 서버는 Electron 내장 Node 로 돌고(`ELECTRON_RUN_AS_NODE=1`), `127.0.0.1` 에만 바인딩합니다. 포트는 8787(사용 중이면 8788~8799).
- 실행 모드는 `claude_code` 입니다. 시험할 때는 환경 변수로 바꿀 수 있습니다: `OFFICE_MODE=mock`,
  `OFFICE_HIVE_DIR`, `OFFICE_DELIVERABLES_DIR`(데이터 위치), `OFFICE_CONCURRENCY`(동시 작업, 기본 2·최대 3).
- 대화형 터미널은 node-pty(`@lydell/node-pty`, Windows ConPTY)로 열고 WebSocket 으로 화면과 주고받습니다. 이 PC 화면에서만 열립니다.
- 설치본에는 live(Agent SDK) 모드 의존성을 넣지 않았습니다(260MB). live 모드는 저장소에서 서버를 직접 띄워 씁니다.

## 개발·빌드 (저장소 루트에서)

```bash
npm install
npm run desktop:dev     # 화면 빌드 후 개발 실행(Electron 창)
npm run desktop:build   # 화면 빌드 후 설치 파일 → release/
npm run desktop:icon    # 아이콘 다시 만들기(desktop/scripts/make-icon.mjs)
```

- 설치 파일에 들어가는 것: `desktop/`(main 프로세스·아이콘), `server/`(hive 데이터·live 의존성 제외), `dist/`, `.claude/agents`, `.claude/skills`.
  빌드하는 PC의 `.claude/skills` 에 사내 스킬이 있으면 그것도 들어가므로, 설치 파일을 외부에 배포하지 않습니다.
- `release/` 는 커밋하지 않습니다.

## 지우기

설정 → 앱 → Wylie AX Office → 제거. `문서\Wylie AX Office` 의 작업 기록·산출물은 남습니다(필요 없으면 직접 지움).
