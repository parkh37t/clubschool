# Wylie AX Office 설치·로그인 안내 (받는 사람용)

이 안내서와 함께 받은 `Wylie-AX-Office-Setup-<버전>.exe` 하나로 설치합니다. 설치한 PC 에서 **자기 Claude 계정**으로 로그인해 씁니다.
사용량은 로그인한 계정의 Claude 구독에 잡히고, 돈이 따로 청구되지 않습니다(API 키를 쓰지 않음).

## 준비물

- Windows 10·11 (64비트)
- Claude Code 를 쓸 수 있는 Claude 구독 계정(Pro·Max 등)과, 그 계정으로 로그인할 브라우저
- 인터넷 연결(Claude Code 설치·로그인·작업 실행에 필요)

## 1. 설치

1. `Wylie-AX-Office-Setup-<버전>.exe` 를 더블클릭합니다.
2. **"Windows의 PC 보호"(SmartScreen) 창**이 뜨면 **[추가 정보] → [실행]** 을 누릅니다. 코드 서명을 하지 않은 사내 설치 파일이라 뜨는 경고입니다.
3. 설치 위치를 확인하고 진행합니다. 내 사용자 계정에만 설치되므로 **관리자 권한이 필요 없습니다**(기본 `%LOCALAPPDATA%\Programs\Wylie AX Office`).
4. 설치가 끝나면 앱이 열립니다. 다음부터는 시작 메뉴·바탕 화면의 **Wylie AX Office** 로 엽니다.

## 2. Claude Code 설치 (처음 한 번)

AX Office 는 Claude Code 로 일합니다. 이 PC 에 Claude Code 가 없으면 화면 위에 **'Claude Code 가 이 PC 에 없습니다'** 가 뜹니다.

1. **[설치하러 가기]** 를 누릅니다. 설정 창 맨 위 **Claude 계정** 칸이 열립니다.
2. **[Claude Code 설치]** → 확인 문구를 읽고 **[설치]**.
   Anthropic 공식 설치 스크립트(`claude.ai/install.ps1`)를 받아 내 사용자 폴더(`%USERPROFILE%\.local\bin`)에 설치합니다. 창은 뜨지 않고 진행 내용이 설정 창에 보입니다.
3. "Claude Code 를 설치했습니다"가 보이면 끝입니다.

Claude 데스크톱 앱이 이미 깔려 있으면 이 단계가 필요 없을 수 있습니다(앱에 들어 있는 Claude Code 를 찾아 씁니다).
직접 깔려면 PowerShell 에서 `irm https://claude.ai/install.ps1 | iex` 를 실행해도 됩니다.

## 3. 내 Claude 계정으로 로그인

1. 화면 위 **'Claude 로그인이 풀려 있습니다'** 배너의 **[로그인]**, 또는 설정 창 **Claude 계정**의 **[로그인]** 을 누릅니다.
   이메일 칸에 내 Claude 계정 메일을 적으면 로그인 화면에 미리 채워집니다(선택).
2. 브라우저에 Claude 로그인 화면이 열립니다. **내 Claude 계정**으로 로그인하고 **승인**합니다.
3. 대부분은 승인하면 바로 끝납니다. 브라우저에 **코드**가 나오면 그 코드를 복사해 설정 창의 **코드 칸**에 붙여 넣고 **[코드 보내기]**.
4. 설정 창에 **'로그인됨 · 내 메일 · 플랜'** 이 보이면 끝입니다. 따로 PowerShell 창은 뜨지 않습니다.

**브라우저가 다른 사람 계정으로 로그인돼 있으면** 그 계정으로 승인됩니다. 브라우저의 claude.ai 에서 먼저 로그아웃하거나,
로그인 진행 칸의 **[주소 복사]** 를 눌러 시크릿 창(Ctrl+Shift+N)에 붙여 넣고 내 계정으로 승인하세요.

**10분 안에 승인하지 않으면** 로그인이 멈춥니다. [로그인]을 다시 누르면 됩니다.

## 4. 쓰기

- 오른쪽 입력창에 맡길 일을 적어 보냅니다. 팀장이 작업으로 나눠 에이전트에게 배정하고, 결과는 `문서\Wylie AX Office\산출물` 에 쌓입니다.
- 금액·인력 수치 확정, 외부 발송 같은 결정은 **승인** 탭에서 직접 합니다.
- 화면 위 사용량 막대에서 구독 사용 한도(5시간·주간)와 오늘 사용 토큰을 봅니다.

## 한 PC 를 여럿이 쓸 때

설정 → **Claude 계정** → **[로그아웃]** → 다음 사람이 자기 계정으로 **[로그인]**.
로그아웃하면 이 PC 의 `claude` 명령도 함께 로그아웃됩니다. 브리핑이 진행 중일 때는 로그인·로그아웃이 막힙니다.

## 알아 둘 것

- 작업 기록·산출물은 이 PC 에만 쌓입니다(`문서\Wylie AX Office`). 다른 PC 와 공유되지 않습니다.
- 사내 제안 스킬·기획 에이전트 패키지는 설치 파일에 들어 있지 않습니다. 내 Claude 계정에 동기화된 스킬이 있으면 쓰고, 없으면 기본 스킬로 돕니다.
- 화면의 결정권자 이름은 아직 '재하'로 나옵니다(내 이름으로 바꾸는 기능은 아직 없음).
- 지우기: Windows 설정 → 앱 → Wylie AX Office → 제거. `문서\Wylie AX Office` 의 기록·산출물은 남습니다.

## 문제가 생기면

| 증상 | 할 일 |
| --- | --- |
| 'Claude Code 가 이 PC 에 없습니다'가 계속 뜸 | 설정 → Claude 계정 → [Claude Code 설치]. 설치 뒤에도 안 보이면 앱을 껐다 켭니다(트레이 아이콘 → 종료) |
| 로그인이 "실패"로 끝남 | 코드를 끝까지 복사했는지 확인하고 [로그인]을 다시 누릅니다 |
| 작업이 '로그인 필요'로 실패 | 로그인이 풀린 것입니다. 3번을 다시 합니다 |
| '사용량 한도' 안내 | 내 구독의 5시간·주간 한도에 닿은 것입니다. 사용량 막대의 재설정 시각 뒤에 다시 보냅니다 |
| API 요금 경고 띠 | 이 PC 환경에 API 키(ANTHROPIC_API_KEY)가 있고 일부러 쓰도록 켠 경우입니다. 담당자에게 문의하세요 |
