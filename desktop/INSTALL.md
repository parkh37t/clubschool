# Wylie AX Office 설치·로그인 안내 (받는 사람용)

이 안내서와 함께 받은 `Wylie-AX-Office-Setup-<버전>.exe` 하나로 설치합니다. 설치한 PC 에서 **자기 Claude 계정**으로 로그인해 씁니다.
사용량은 로그인한 계정의 Claude 구독에 잡히고, 돈이 따로 청구되지 않습니다(API 키를 쓰지 않음).

## 준비물

- Windows 10·11 (64비트)
- Claude Code 를 쓸 수 있는 Claude 구독 계정(Pro·Max 등)과, 그 계정으로 로그인할 브라우저
- 인터넷 연결(Claude Code 설치·로그인·작업 실행에 필요)

## 1. 설치

1. `Wylie-AX-Office-Setup-<버전>.exe` 를 더블클릭합니다.
2. **"Windows의 PC 보호"(SmartScreen) 창**이 뜨면 **[추가 정보] → [실행]** 을 누릅니다. 코드 서명을 하지 않은 사내 설치 파일이라 뜨는 경고입니다.
   - 메신저·메일로 받은 zip 은 압축을 풀기 전에 zip 파일 오른쪽 클릭 → **속성** → 아래쪽 **'차단 해제'** 체크 → 확인을 먼저 하면 덜 막힙니다.
   - **"스마트 앱 컨트롤이 안전하지 않을 수 있는 앱을 차단했습니다"** 가 뜨면 앱별 예외가 없습니다. Windows 보안 → 앱 및 브라우저 컨트롤 →
     스마트 앱 컨트롤 설정 → **끄기** 를 해야 설치됩니다(끄면 다시 켜기 어려울 수 있으니 PC 주인·담당자와 정합니다).
3. 설치 위치를 확인하고 진행합니다. 내 사용자 계정에만 설치되므로 **관리자 권한이 필요 없습니다**(기본 `%LOCALAPPDATA%\Programs\Wylie AX Office`).
4. 설치가 끝나면 앱이 열립니다. 다음부터는 시작 메뉴·바탕 화면의 **Wylie AX Office** 로 엽니다.

## 2. Claude Code 설치 (처음 한 번)

AX Office 는 Claude Code 로 일합니다. 이 PC 에 Claude Code 가 없으면 화면 위에 **'Claude Code 가 이 PC 에 없습니다'** 가 뜹니다.

1. **[설치하러 가기]** 를 누릅니다. 설정 창 맨 위 **Claude 계정** 칸이 열립니다.
2. **[Claude Code 설치]** → 확인 문구를 읽고 **[설치]**.
   Anthropic 공식 설치 스크립트(`claude.ai/install.ps1`)를 받아 내 사용자 폴더(`%USERPROFILE%\.local\bin`)에 설치합니다. 창은 뜨지 않고 진행 내용이 설정 창에 보입니다.
3. "Claude Code 를 설치했습니다"가 보이면 끝입니다.

Claude 데스크톱 앱이 이미 깔려 있으면 이 단계가 필요 없을 수 있습니다(앱에 들어 있는 Claude Code 를 찾아 씁니다).
직접 깔려면 PowerShell 에서 `irm https://claude.ai/install.ps1 | iex` 를 실행해도 됩니다.

## 3. 내 Claude 계정으로 로그인

1. 화면 위 **'Claude 로그인이 풀려 있습니다'** 배너의 **[로그인]**, 또는 설정 창 **Claude 계정**의 **[로그인]** 을 누릅니다.
   이메일 칸에 내 Claude 계정 메일을 적으면 로그인 화면에 미리 채워집니다(선택).
2. 브라우저에 Claude 로그인 화면이 열립니다. **내 Claude 계정**으로 로그인하고 **승인**합니다.
3. 대부분은 승인하면 바로 끝납니다. 브라우저에 **코드**가 나오면 그 코드를 복사해 설정 창의 **코드 칸**에 붙여 넣고 **[코드 보내기]**.
4. 설정 창에 **'로그인됨 · 내 메일 · 플랜'** 이 보이면 끝입니다. 따로 PowerShell 창은 뜨지 않습니다.

**브라우저가 다른 사람 계정으로 로그인돼 있으면** 그 계정으로 승인됩니다. 브라우저의 claude.ai 에서 먼저 로그아웃하거나,
로그인 진행 칸의 **[주소 복사]** 를 눌러 시크릿 창(Ctrl+Shift+N)에 붙여 넣고 내 계정으로 승인하세요.

**10분 안에 승인하지 않으면** 로그인이 멈춥니다. [로그인]을 다시 누르면 됩니다.

## 4. 내 이름 넣기 (처음 한 번)

설정 창 **결정권자 이름**에 내 이름(한국어·영어)을 적고 **[저장]** 합니다. 화면·승인 카드·보고서와 팀장·에이전트 지시문에 이 이름이 쓰입니다.
비워 두면 기본 이름 '재하'로 나오고, 한쪽만 적으면 다른 언어 화면에서도 그 이름을 씁니다. 이미 남은 기록(지난 승인·보고서)의 이름은 바뀌지 않습니다.

## 5. 쓰기

- 오른쪽 입력창에 맡길 일을 적어 보냅니다. 팀장이 작업으로 나눠 에이전트에게 배정하고, 결과는 `문서\Clubschool AX Office\산출물` 에 쌓입니다.
- 금액·인력 수치 확정, 외부 발송 같은 결정은 **승인** 탭에서 직접 합니다.
- 화면 위 사용량 막대에서 구독 사용 한도(5시간·주간)와 오늘 사용 토큰을 봅니다.

## 6. 기획 에이전트 패키지 (화면설계를 쓸 때만)

화면설계(기획) 브리핑을 표준 기획 프로세스(요구 원장 → 작업가이드·IA → 화면 생성 → 리뷰 → 인계)로 돌리는 패키지입니다(화면 규격·린트·검증·골든 화면·팩 템플릿).
**설치 파일에 들어 있어 처음 켤 때 저절로 연결됩니다** — `문서\Clubschool AX Office\기획 에이전트 패키지\wylie-plan-agent` 에 복사되고, 설정 창
**기획 에이전트 패키지** 칸에 '연결됨' 으로 보입니다. 따로 할 일은 Python 설치뿐입니다.

1. **Python 3 설치** — 패키지의 스크립트(화면 뼈대 만들기·린트·검증)를 앱이 Python 으로 돌립니다.
   python.org 에서 Windows 설치 파일을 받아 설치할 때 **"Add python.exe to PATH" 를 체크**합니다. 추가로 깔 라이브러리는 없습니다.
   설치 뒤 앱을 껐다 켜면 설정 창 기획 에이전트 패키지 칸에 '패키지 스크립트 실행: Python 3.x' 가 보입니다(없으면 설치 안내가 빨간 글로 뜸).
2. **(필요할 때) 다른 패키지로 바꾸기** — 설정 창 → **기획 에이전트 패키지** → **[폴더 고르기]** → `scripts`·`packs`·`core` 가 보이는 폴더 → **[연결]**.
   한 번 자동 연결한 뒤에는 [끄기]로 끊어도 다시 저절로 연결하지 않습니다. 이 PC 에 이미 연결된 패키지가 있으면 자동 연결은 그것을 그대로 둡니다.
3. **쓰기** — 결과 줄에 화면설계를 적은 브리핑을 보내면 기획 6단계로 나뉘고, **기획** 탭에서 팩·화면을 봅니다.
   첫 화면설계 브리핑을 보내면 팩이 `packs\_template` 을 바탕으로 저절로 만들어지고, 작업가이드·IA 를 확정(승인 '가이드확정')한 뒤 화면을 만듭니다.
   다음 차수는 기획 탭의 **[이 팩으로 화면설계 브리핑]** 으로 이어 갑니다.

설치 파일에 든 패키지에는 예시(데모) 팩이 없습니다 — 빈 템플릿에서 시작합니다.

## 한 PC 를 여럿이 쓸 때

설정 → **Claude 계정** → **[로그아웃]** → 다음 사람이 자기 계정으로 **[로그인]**하고, **결정권자 이름**도 자기 이름으로 바꿉니다.
로그아웃하면 이 PC 의 `claude` 명령도 함께 로그아웃됩니다. 브리핑이 진행 중일 때는 로그인·로그아웃이 막힙니다.
같은 Windows 계정으로 쓰면 작업 기록·산출물(`문서\Clubschool AX Office`)도 같이 쓰므로 앞사람의 승인·대화 기록이 그대로 보입니다.

## 알아 둘 것

- 작업 기록·산출물은 이 PC 에만 쌓입니다(`문서\Clubschool AX Office`). 다른 PC 와 공유되지 않습니다.
- 기획 에이전트 패키지는 설치 파일에 들어 있어 처음 켤 때 저절로 연결됩니다(6번). 사내 제안 스킬은 들어 있지 않습니다 — 내 Claude 계정에 동기화된 스킬이 있으면 쓰고, 없으면 기본 스킬로 돕니다.
- 지우기: Windows 설정 → 앱 → Wylie AX Office → 제거. `문서\Clubschool AX Office` 의 기록·산출물은 남습니다.

## 문제가 생기면

| 증상 | 할 일 |
| --- | --- |
| 'Claude Code 가 이 PC 에 없습니다'가 계속 뜸 | 설정 → Claude 계정 → [Claude Code 설치]. 설치 뒤에도 안 보이면 앱을 껐다 켭니다(트레이 아이콘 → 종료) |
| 로그인이 "실패"로 끝남 | 코드를 끝까지 복사했는지 확인하고 [로그인]을 다시 누릅니다 |
| 작업이 '로그인 필요'로 실패 | 로그인이 풀린 것입니다. 3번을 다시 합니다 |
| 화면 생성 단계가 실패하고 python 을 찾지 못한다는 안내 | Python 3 를 설치하며 "Add python.exe to PATH" 를 체크했는지 확인하고, 앱을 껐다 켭니다(6번) |
| 작업이 '시간 안에 끝나지 않았습니다'로 실패 | 실패한 작업 카드의 **[다시 실행]** 을 누릅니다. 큰 자료를 다루면 설정 → 동작 → 작업 1건 시간 제한을 늘립니다 |
| '사용량 한도' 안내 | 내 구독의 5시간·주간 한도에 닿은 것입니다. 사용량 막대의 재설정 시각 뒤에 다시 보냅니다 |
| API 요금 경고 띠 | 이 PC 환경에 API 키(ANTHROPIC_API_KEY)가 있고 일부러 쓰도록 켠 경우입니다. 담당자에게 문의하세요 |
