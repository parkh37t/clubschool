# 수주 판단 · 제안 전략 — 그린마일(GreenMile) 자사몰 리뉴얼 RFP

- 작성: 한도전 (영업·평가 팀장)
- 문서 버전: v1
- 대상 RFP 요약: 친환경 D2C 브랜드(연매출 약 180억) 자사몰 전면 리뉴얼 + 구독(정기배송) 커머스 +
  개인화(AI) 상품추천, 카페24 임대몰 → 헤드리스 커머스 전환. 예산 3.5억(VAT 별도),
  기간 5개월, **6월 성수기 오픈 마감 고정**. 평가배점 기술60/가격30/실적10.
  회원 12만 명 이관, 오프라인 팝업 재고 실시간 연동 포함.

> **가정 표기 원칙**: 이 문서에서 RFP 원문에 없는 수치·전제는 모두 "가정"으로 별도 표기했습니다.
> 김영업의 현장 조사(경쟁사·현 벤더·발주사 내부 사정)로 확인·보정이 필요합니다.

## 1. 수주 판단: **Conditional-Go**

### 결론 먼저
**스코프를 그대로 수락하면 No-Go에 가깝고, 스코프를 재정의(단계화)하는 조건으로 참여하면
Go에 가깝다.** 따라서 최종 판단은 **Conditional-Go**입니다. 제안서 제출 전 아래 3가지 중
최소 2가지가 확보되지 않으면 입찰 포기(No-Go 전환)를 권고합니다.

- 오프라인 팝업 재고 실시간 연동을 **2차 phase(오픈 이후)** 로 분리하는 데 발주사가 동의
- AI 개인화 추천을 **자체 AI 개발이 아닌 검증된 추천 솔루션 연동**으로 해석하는 데 발주사가 동의
- 6월 오픈이 **핵심 플로우(상품탐색-장바구니-구독결제) 우선 오픈**이며, 전체 기능 완성 마감이
  아니라는 데 발주사가 동의(가정: RFP상 "성수기 오픈"의 정확한 착수월·목표월 확인 필요)

### 5개 축 평가 (5점 척도, 5=매우 유리 / 1=매우 불리)

| 축 | 점수 | 근거 |
| --- | :---: | --- |
| 적합도 (우리 역량 ↔ 요구사항) | 3/5 | 조직 내 헤드리스 커머스 구축 레퍼런스 보유 여부 **확인필요(가정)**. 백엔드 전담 1명 규모 구성상 신규 아키텍처+대량 이관을 동시 수행하는 R&D형 프로젝트는 도전적. UI/기획/퍼블리싱 역량은 매칭됨. |
| 수익성 (예산 3.5억 대비 마진) | 2/5 | 개략 견적(5절) 기준 명목 마진율 약 21%로 업계 평균 수준이나, 5개 고난도 항목(헤드리스·구독·AI추천·회원이관·재고연동)이 겹쳐 실투입 MM이 20~30% 초과할 개연성이 높고, 이 경우 실질 마진은 한 자릿수%까지 떨어질 위험. |
| 난이도 (구현 복잡도, 낮을수록 유리) | 2/5 | 카페24 임대몰 → 헤드리스 전환은 그 자체로 통상 6개월 이상 소요되는 규모의 과제. 여기에 구독결제, 추천엔진 연동, 12만 회원 이관, 오프라인 POS 재고 연동까지 5개월 내 동시 진행은 고난도. |
| 경쟁강도 (낮을수록 유리) | 2/5 | 헤드리스 커머스 전환은 대형 커머스 SI·카페24 자체 확장 제안 등과 경쟁할 가능성 높음(**가정, 확인필요** → 김영업 조사 요청). 가격 배점 30점이 커서 저가 입찰 경쟁 우려. |
| 리스크 (낮을수록 유리) | 2/5 | 마감 고정 + 다중 이관/연동이 겹쳐 일정 리스크가 구조적으로 큼(3절 상세). |
| **총점** | **11/25 (44%)** | 15점 이상 Go, 10~14점 Conditional-Go, 9점 이하 No-Go 기준선 적용 |

### 총평
스코프를 있는 그대로 수락하면 "가격 경쟁력 있는 대형 SI가 이길 확률이 높은 판"에서
"우리가 실행 리스크만 떠안는 구조"가 될 소지가 큽니다. 반대로 **스코프를 단계화하고
기술 승부처(헤드리스 전환 방식, 추천 구현 방식)를 명확히 좁히면**, 기술 배점 60점이
크다는 점을 역이용해 "실행 가능성으로 이기는" 그림이 가능합니다. 조건이 충족되지 않으면
계약 후 지연·역마진 리스크가 크므로, 조건 미충족 시에는 **정중히 No-Go(또는 부분 제안)**
로 전환할 것을 권고합니다.

## 2. 핵심 요구·평가기준 해석

### 발주사가 표면적으로 말한 것 vs 진짜 원하는 것

| 표면 요구 | 숨은 니즈(추정) | 근거/가정 |
| --- | --- | --- |
| "헤드리스 커머스로 전환" | 임대몰(카페24)의 커스터마이징·확장성 한계로 인한 **매출 손실 해소**(성수기 트래픽, 프로모션 유연성, 구독결제 자동화 부족) | 임대몰 → 헤드리스 전환 요구는 통상 "더 이상 플랫폼 제약 때문에 마케팅/프로모션을 놓치고 싶지 않다"는 신호. **가정**: 실제 트래픽·매출 데이터는 미확인, 확인필요 |
| "AI 기반 개인화 추천" | 정교한 자체 AI 모델이 아니라 **"우리도 개인화한다"는 대외 메시지 + 실질적 전환율 개선** | "AI 기반" 명시는 투자자/브랜드 커뮤니케이션용일 가능성. 자체 개발 여부는 협상 여지 있음(4절 전략 연결) |
| "6월 성수기 오픈 필수" | 마케팅 캘린더(환경 관련 시즌, 여름 성수기)와 결합된 매출 목표 — **일정이 품질보다 우선순위 1위** | 마감 고정이 RFP에 명시된 만큼, 제안 평가에서도 "일정 준수 신뢰도"가 실질적으로 기술 배점에 강하게 반영될 가능성 |
| "오프라인 팝업 재고 실시간 연동" | 옴니채널 브랜드 경험 확장 전략의 일환. 다만 자사몰 리뉴얼의 **핵심 성공 지표는 아닐 가능성** | 팝업은 이벤트성 채널로, 온라인 매출 임팩트보다 브랜드 경험 목적일 개연성 → 협상(2차 phase화) 대상으로 적합 |
| "회원 12만 명 이관" | 기존 고객 자산(구매이력·포인트·등급) 손실 없는 **무중단 전환**에 대한 강한 불안 | 이관 실패 시 고객 이탈·CS 폭증이 발주사 입장에서 가장 두려운 시나리오 |

### 평가기준(기술60 / 가격30 / 실적10) 공략 관점

- **기술 60점 — 가장 큰 승부처.** 배점 구조상 "무엇을 만들 수 있는가"보다 **"이 일정과 예산
  안에서 안전하게 만들 수 있는가"** 를 증명하는 쪽이 유리합니다. 신기술 나열보다 헤드리스
  전환 방식의 구체성(어떤 스택, 어떤 리스크 완화책), 추천 구현의 현실적 근거(데이터 준비
  상태·연동 방식), 회원 이관 리허설 계획을 구체적으로 제시하는 것이 배점을 가져오는 방법.
- **가격 30점 — 무리한 저가 대응은 지양.** 3.5억이라는 예산 자체가 명시돼 있으므로,
  "얼마나 싼가"보다 **"예산 안에서 무엇을 우선순위화했는가"** 를 투명하게 보여주는 것이
  가격 항목에서도 신뢰를 얻는 방법(5절 견적 참조). 대형 SI가 초저가로 들어올 경우
  스코프 삭제·인력 저가 투입 우려를 간접적으로 부각.
- **실적 10점 — 비중 낮음, 치명적이지 않음.** 헤드리스 커머스 완전 동일 레퍼런스가 없어도
  큰 감점 요인은 아님. 유사 규모 D2C/커머스 리뉴얼 실적 + 짧은 데모/프로토타입으로 보완 가능.

## 4. 승률 제고 제안 전략

### 우리 차별화 포인트
- **"헤드리스-라이트(Headless-lite)" 접근**: 처음부터 완전 자체 아키텍처를 새로 짜기보다,
  검증된 헤드리스 커머스 엔진 위에 프론트엔드(Next.js 등)만 완전 분리해 커스터마이징 자유도와
  일정 안전성을 동시에 확보하는 방식 제안. "새로 만드는 리스크"가 아니라 "검증된 위에서
  빠르게 만드는" 메시지로 대형 SI의 "풀 커스텀 개발" 제안과 차별화.
- **AI 추천 = 자체 모델 개발이 아닌 "검증된 추천 엔진 + 우리 데이터 파이프라인"**: 실현
  가능성과 일정 안전성을 동시에 확보하면서도 "AI 기반" 요구를 충족.
- **이관 리허설 프로세스**: 12만 회원 이관을 "이벤트"가 아니라 "리허설을 거친 검증된 절차"로
  제시 — 발주사가 가장 불안해할 지점을 정면으로 다룸.

### 킬러 메시지
> **"성수기 오픈은 타협 대상이 아닙니다. 저희는 새로 만드는 리스크 대신, 검증된 기반 위에서
> 빠르게 만들어 일정을 지킵니다."**

### 데모/PoC 제안 여부
- **제안**: 정식 제안서에 실동작 코드 PoC보다는 **핵심 플로우(상품탐색 → 장바구니 →
  구독결제 → 추천 노출) 클릭형 프로토타입**을 첨부해 "우리는 이미 그림을 그려봤다"는
  신뢰를 준다 (정우선/나기획과 협업 필요, 제안 기간 내 소화 가능한 현실적 범위).
- 실동작 코드 기반 PoC는 제안 단계 예산·일정상 무리이므로 **제안 단계에서는 수행하지 않음**
  (가정: 제안 준비 기간이 통상 2~4주로 제한적이라는 전제. 실제 제안 마감일 확인필요).
