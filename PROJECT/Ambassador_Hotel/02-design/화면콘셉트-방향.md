# 화면 콘셉트 방향 — 앰배서더 호텔 (과제 #2, Pre-RFP 선제작)

> 담당: 차도안(UI)·오색감(BX) · skill: `design-system-build`·`brand-guideline`
> 산출: 본 방향서 + 콘셉트 보드 `DELIVERABLES/Ambassador_Hotel/02_디자인/화면콘셉트_v1.html`
> 목적: RFP 발행 전 "보여주는 카드" 확보(시안 우위 부각). ⚠ 색/이미지는 제안용 방향 시안(확정 아님).

## 1. 무드 / 브랜드 톤
- 키워드: **환대(Hospitality) · 신뢰 · 절제된 럭셔리 · 글로벌**.
- 인상: 풀블리드 이미지 + 절제된 세리프 디스플레이 + 여백. 과장 모션 지양.

## 2. 컬러/타이포 방향 [추측: 확정 BI 전 근사]
| 토큰 | 값 | 용도 |
| --- | --- | --- |
| Navy(primary) | `#11203A` | 헤더·신뢰·텍스트 |
| Gold(accent) | `#B89150` | 강조·CTA·등급 |
| Cream(surface) | `#F6F1E7` | 배경·카드 |
| Ink | `#2A2E37` | 본문 |
- 타이포: Display=세리프(Playfair 계열), Body=산세리프(Inter). 럭셔리·가독 균형.

## 3. 핵심 화면 (제안 시연 우선순위)
1. **홈 히어로 + 예약 위젯** — 풀블리드 비주얼 + 상단 고정 예약바(지점·날짜·인원). 직예약 전환 강조.
2. **멤버십/CRM 여정** — 등급·포인트·회원 전용가·마이페이지. 홈↔CRM 데이터 연결(차세대 명분).
3. **객실/다이닝 디스커버리** — 카드 그리드·필터, 비주얼 중심.
4. (확장) 다국어/글로벌·접근성 — 인바운드 외국인 대응(타 과제 자산 재사용).

## 4. UX 원칙
- 모바일 퍼스트 예약·멤버십, 최소 단계, 명확한 CTA(Gold).
- 멤버 혜택을 홈에서 즉시 노출(전환).
- WCAG AA·다국어 셀렉터·게스트 체크아웃.

## 핸드오프
- 콘셉트 승인 시 → 나기획(IA·플로우) → 차도안(시안 확장) → 표준수·이풍뎅(핵심 화면 퍼블 샘플).
