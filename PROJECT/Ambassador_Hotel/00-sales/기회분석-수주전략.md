# 기회 분석 & 수주 전략 — 앰배서더 호텔 홈페이지/CRM 차세대 (과제 #2)

> 담당: 한도전(수주 전략)·김영업(경쟁·정보) · skill: `rfp-analysis`(사전)·`competitor-benchmark`

## 1. 사업 개요 (사실)
| 항목 | 내용 |
| --- | --- |
| 사업 | 앰배서더 호텔 홈페이지/CRM 차세대 — UX/UI 전면 개편 + AWS 신규 구축 (AI는 선택) |
| 상주 | 비상주 (초기 PM·일부 PL 반상주) |
| 예산 | 고객 언급 **19~20억** |
| 일정 | RFP 다음 주 수 발행 → 제안 2~3주 → **내년 AI 사업으로 연결되는 다년 기회** |
| 구도 | 와일리 vs 아이온 컨소시엄 vs 신세계 I&C → **와일리·아이온 연합 시 사실상 2파전** |
| 우리 포지션 | **와일리 = UIUX 집중**, **아이온 = 주관(개발)**. 이번 판은 개발 주관 + UIUX 분담 |

## 2. 우리(와일리) 역할 정의
- 컨소시엄 내 **UIUX 전담**. 개발/AWS/AI는 아이온 주관.
- 우리 팀 워크플로우 매핑: **기획(IA·플로우·화면정의) → 디자인(UIUX·디자인시스템) → 퍼블리싱(마크업·인터랙션·접근성)**.
- 아이온 기존 에이전시 이탈 협의 진행 + 해당 인력 일부 **와일리 수용 조건** (분담·인력 통합 이슈로 관리).

## 3. 경쟁 구도 (와일리+아이온 vs 신세계 I&C)
| 축 | 와일리+아이온(우리) | 신세계 I&C |
| --- | --- | --- |
| 디자인/UX | **강점** — 와일리 시안 품질 고객 인정·호감 높음(과거 아이온 시안 열위는 연합으로 해소) | 특이사항 없음 |
| 기술/개발 | **강점** — 아이온 기술력 고객 인정, **AI 데모 기제시** | 대형 SI 신뢰감 |
| 도메인 이해 | **강점** — PM 내정자 여행업 20년·업계 1위 경험, 총괄 PM 직접 투입 카드 | 여행/호텔 도메인 이해 부족 평가 |
| 가격 | 유연 — 마진선 방어 수준 대응(가견적 ~17억, 평단가 1000만↑ 확인) | 단가 높음 |
| 영업 | **우위** — 발주처 상위 라인 사전 교감 확보(내부 보안), 실무 긍정 반응 | 영업 담당 3~4회 교체로 히스토리 단절, 적극 영업 정황 미확인 |

## 4. SWOT (컨소시엄/우리 관점)
- **S**: UIUX 시안 경쟁력, 개발+AI(아이온), 도메인 PM, 영업 교감, 가격 유연.
- **W**: 컨소 분담·기존 에이전시 인력 수용에 따른 조직 통합 리스크, 비상주 협업 난이도.
- **O**: 다년(내년 AI) 연계, 2파전 구도, 신세계 영업 미온적 정황.
- **T**: 신세계 동향 불투명, RFP·제안 일정 촉박, 예산 대비 평단가 방어.

## 5. 수주 전략 (승부수)
1. **UIUX로 승부를 본다** — 와일리 시안 품질을 제안 차별화 1번으로. 호텔/CRM 맞춤 화면 콘셉트 선제 제시.
2. **연합 시너지 서사** — "디자인(와일리)+기술·AI(아이온)+도메인(PM 20년)"의 결합을 단일 메시지로.
3. **AI 다년 로드맵** — 이번(선택) AI를 내년 본 사업으로 잇는 단계적 로드맵으로 미래가치 제시.
4. **영업 교감 유지** — 상위/실무 라인 관계(내부 보안)를 신뢰 기반으로 활용(문서화 금지).
5. **가격 유연성** — 마진선 방어 범위에서 평단가·볼륨 협의(아래 §6).

## 6. 가격/볼륨 전략
- 와일리 UIUX 볼륨: 아이온 기존 가정 ~5억, 우리 2년전 견적(**PM·퍼블 제외 ~5억**) → 수주 시 **유연 협의 가능**.
- 컨소 가견적 ~17억(예산 19~20억 대비 여유), 평단가 ~1000만↑.
- 전략: UIUX 볼륨을 품질 근거로 방어하되, 컨소 총액 경쟁력(신세계 대비 단가 우위) 유지.
