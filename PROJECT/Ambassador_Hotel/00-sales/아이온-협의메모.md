# 아이온 협의 메모 — R&R · 볼륨 · 인력 (엠배서더 컨소시엄)

> ⚠ 대외비 · 내부 협의용 · 담당: 한도전(정우선 배석) · 상대: 아이온(주관·개발)
> 목적: 제안 전 와일리(UIUX)–아이온(개발) 분담·볼륨·인력 수용을 합의문안 수준으로 정렬.

## 1. 협의 배경 (RFP 반영)
- 예산 **12억 이내**(AWS·APM 제외) — 사전 영업 인텔(19~20억)과 차이 → **분담·볼륨 재산정 필수**.
- 기간 10~11개월, 우리 핵심 = P2 설계·P3 디자인(+P4 퍼블 지원).

## 2. R&R 합의안 (제안)
| 영역 | 와일리 | 아이온 |
| --- | --- | --- |
| 분석(P1) | UX 관점 요구 상세화 | 아키텍처·WBS 총괄 |
| 설계(P2) | IA·UX Flow·와이어프레임·화면설계서 | ERD·API 명세·시스템 설계 |
| 디자인(P3) | UI 시안 3종·디자인시스템·스타일가이드 | — |
| 개발(P4) | 퍼블 가이드·접근성 감수·디자인 QA | 웹/앱(RN·Flutter)·부킹엔진·PG·CRM·메타서치 |
| 테스트/오픈 | UI/접근성 검수 지원 | 통합·이행·안정화 |
| 총괄 PM | UIUX PL(반상주 가능) | 프로젝트 총괄 PM |

## 3. 볼륨/단가 (협의 포인트)
- 와일리 UIUX 볼륨: 2년전 견적(PM·퍼블 제외 ~5억) 기준, **예산 12억 전제로 재산정**.
- 옵션: (a) 설계+디자인 코어, (b) +퍼블 포함, (c) +운영(ITO) UI 유지보수.
- 목표: 품질 근거로 볼륨 방어하되 컨소 총액 경쟁력(vs 신세계) 유지.

## 4. 기존 에이전시 인력 수용 (조건)
- 수용 인원·역할·단가·합류 시점 합의 필요. 와일리 품질 기준·조직 적합성 우선.
- 통합 리스크(역할 중복·책임 경계) 관리 — 합류 시 R&R 재확인.

## 5. 협업 모델
- 비상주(초기 PM·일부 PL 반상주), 형상관리(Git)·산출물 공유·주간 동기화.
- 제안 작성 분담: 와일리=UIUX 파트 전담, 합동 리허설.
