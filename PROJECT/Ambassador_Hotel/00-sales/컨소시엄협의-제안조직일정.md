# 컨소시엄 협의 · 제안 조직 · 일정 — 앰배서더 호텔 (과제 #2)

> ⚠ CONFIDENTIAL — 인적 관계(내부 보안)는 구두 관리, 본 문서 비기재.

## 1. 아이온(주관)–와일리(UIUX) 협의 포인트
| 항목 | 우리 입장/목표 | 합의 필요 |
| --- | --- | --- |
| R&R 경계 | 와일리=UX/UI(기획·디자인·퍼블), 아이온=개발/AWS/AI/PM총괄 | 화면 정의·퍼블 산출물 인계 기준, API/데이터 인터페이스 책임선 |
| UIUX 볼륨 | 2년전 견적(PM·퍼블 제외 ~5억) 기준, **유연 협의** | 최종 볼륨·단가, 퍼블 포함 여부 |
| 기존 에이전시 인력 수용 | 일부 와일리 수용(조건부) | 수용 인원·역할·단가·합류 시점 |
| 협업 모델 | 비상주(초기 PM·일부 PL 반상주) | 형상관리·커뮤니케이션·산출물 공유 체계 |
| AI(선택) | 내년 AI 다년 사업으로 연결 | 이번 제안의 AI 범위·분담 |
| 제안 작성 분담 | 와일리=UIUX 파트 전담 작성 | 제안서 목차상 분량·리허설 역할 |

| 역할 | 담당 | 비고 |

## 3. 일정 역산 (RFP 다음 주 수 발행 → 제안 2~3주)
| 주차 | 와일리 작업 | 산출물 |
| --- | --- | --- |
| W0 (RFP 발행 전) | 준비물 선제작(역량팩·화면 콘셉트·아이온 합의) | 콘셉트 시안 초안, 협의 메모 |
| W1 | RFP 분석·UIUX 요구 분해, IA·핵심 플로우 | 요구 매트릭스, IA 초안 |
| W2 | UIUX 시안·디자인시스템·핵심 화면 퍼블 샘플 | 시안, 프로토타입(샘플), 제안서 UIUX 파트 초안 |
| W3 | 제안서/발표자료 통합·리허설(아이온 합동) | 제안서(DOCX)·발표(PPTX)·프로토타입(HTML) |
> 2주 압축 시 W2·W3 병행. 산출물은 Claude-native 생성으로 속도 확보.

## 4. 의사결정/확인 필요
- 아이온과 **UIUX 볼륨·인력 수용·R&R** 최종 합의(한도전).
- RFP 실제 요구·배점·AI 범위(발행 후 즉시 반영).
- 반상주 인력·기간 확정(정우선).
