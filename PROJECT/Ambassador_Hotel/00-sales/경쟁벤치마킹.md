# 경쟁 벤치마킹 — 앰배서더 호텔 (과제 #2)

> 담당: 김영업 · skill: `competitor-benchmark`
> ⚠ 라이브 웹조사 미반영분은 [일반지식]/[추측] 표기. 입찰 경쟁 정보는 영업 메일(사실) 기반.

## 1. 입찰 경쟁 — 와일리+아이온 vs 신세계 I&C
| 비교 축 | 와일리+아이온(우리) | 신세계 I&C | 근거 |
| --- | --- | --- | --- |
| 디자인/UX | ◎ 시안 품질 고객 인정·호감 | △ 특이사항 없음 | 영업 메일(사실) |
| 기술/개발·AI | ◎ 기술력 인정, AI 데모 기제시 | ○ 대형 SI 신뢰감 | 영업 메일 |
| 도메인(호텔/여행) | ◎ PM 여행 20년·업계 1위 경험 | ✕ 도메인 이해 부족 평가 | 영업 메일 |
| 가격 | ◎ 유연(가견적 ~17억, 평단가 1000만↑) | △ 단가 높음 | 영업 메일 |
| 영업/관계 | ◎ 상위 라인 교감(내부 보안) | ✕ 담당 3~4회 교체·히스토리 단절 | 영업 메일 |
| 종합 | **우위(2파전 주도)** | 추격 | — |

→ 시사점: **약점이 거의 없는 구도.** 단 "신세계 영업 미온"은 소문 수준이므로 과신 금지(지속 모니터링).

## 2. 호텔 홈페이지/CRM UX 벤치마킹 (피어·베스트프랙티스) [일반지식]
> 비교 대상: 국내(신라·롯데·조선팰리스), 글로벌 체인(Accor/Marriott/Hilton), 앰배서더 현행.
| UX 영역 | 베스트프랙티스 패턴 | 앰배서더 적용 시사점 |
| --- | --- | --- |
| 예약(Booking) | 상단 고정 예약 위젯(지점·날짜·인원), 최소 단계, 요금 캘린더, 게스트체크아웃 | 직예약 전환 극대화 — "최저가 직예약" 강조, 단계 축소 |
| 멤버십/로열티 | 등급·포인트 가시화, 회원 전용가, 가입 인센티브, 마이페이지 여정 | CRM 핵심 — 회원가 차별·등급 혜택을 홈에서 즉시 노출 |
| 다국어/글로벌 | 언어·통화 셀렉터, 외국인 결제수단, i18n 일관 | 인바운드 외국인 고객 대응(IBK 과제서 축적한 다국어·접근성 자산 재사용 가능) |
| 비주얼/브랜드 | 풀블리드 이미지, 절제된 럭셔리 타이포, 모션 절제 | 앰배서더 브랜드 격에 맞는 "환대·신뢰" 톤 |
| 모바일 | 모바일 우선 예약·멤버십, 빠른 로딩 | 모바일 전환 비중 큼 → 모바일 퍼스트 |
| CRM 연계 | 예약·멤버십·마케팅 데이터 통합, 개인화 추천 | 차세대 핵심: 홈페이지↔CRM 끊김 없는 데이터 여정 |
| 접근성 | WCAG AA, 키보드/스크린리더 | 공공성·외국인 대응 차원 강점화 |

## 3. 우리 UIUX 승부 포인트 (벤치마킹 → 전략)
1. **직예약 전환 UX** — 예약 위젯·플로우 단축을 핵심 KPI로(요율/직예약 강조).
2. **멤버십·CRM 여정 통합** — 홈↔마이페이지↔CRM 데이터 끊김 제거(차세대 명분).
3. **럭셔리 브랜드 톤** — 절제된 비주얼·타이포로 격조(시안 우위 부각).
4. **글로벌/다국어·접근성** — 인바운드 외국인 대응(타 과제 자산 재활용 → 차별화·효율).
5. **AI 연계 떡밥** — 개인화 추천·챗 컨시어지 등 내년 AI 다년 로드맵으로 연결.
