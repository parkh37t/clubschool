# IA · 사이트맵 · 핵심 플로우 — 엠배서더호텔 (과제 #2)

> ⚠ 대외비 · 담당: 나기획 · skill: `ia-flow-design` · P2 설계 산출물

## 1. 사이트맵 (정보구조)
```
엠배서더 홈
├─ 홈(메인) — 배너/프로모션·추천 숙소·빠른 검색·최근 본
├─ 검색/리스트 — 키워드·필터·정렬·지도뷰·찜
│   └─ 숙소 상세 — 사진·편의시설·리뷰·Sticky 예약 CTA
│       └─ 예약/결제 — 정보입력 → 결제(간편결제) → 완료/알림
├─ 다이닝 — 레스토랑 목록 → 좌석 예약/확인
├─ 멤버십 — 등급·혜택·회원가·가입
├─ E-Shop — 상품 목록 → 상세 → 구매/예약 → 리뷰
├─ 프로모션/이벤트 — 스페셜 오퍼·응모(DB수집)
├─ 마이페이지 — 예약내역·찜·쿠폰/포인트·리뷰·바우처
└─ (관리자) — 대시보드·회원·숙소·예약·쿠폰·CMS·상품권·E-Shop
```

## 2. 글로벌 내비게이션
- 상단: 로고 · 객실 · 다이닝 · 멤버십 · 프로모션 · E-Shop · (KR/EN) · 로그인 · 멤버 가입
- 모바일 탭바: 홈 · 검색 · 찜 · 멤버십 · MY

## 3. 핵심 플로우

### Flow 1 — 직접 예약 (전환 핵심)
```
홈/검색 → [빠른검색: 지점·날짜·인원] → 검색결과(필터·지도) → 숙소 상세
 → 예약 신청(날짜·인원 확인, Step 최소화) → [로그인?] 
     ├ 회원 → 회원가·쿠폰/포인트 적용 → 결제(간편결제) → 완료(이메일/푸시)
     └ 비회원 → 게스트 체크아웃 → 결제 → 완료 + 가입 유도
   [예외] 실시간 가용 없음 → 대체 날짜 추천 / 결제 실패 → 재시도
```

### Flow 2 — 멤버십 전환·로열티
```
비회원 예약 완료 → 가입 유도(혜택 미리보기) → 가입 → 등급/포인트 부여
 → 마이페이지(포인트·바우처·소멸 알림) → 회원가 재예약(재방문)
```

### Flow 3 — 바우처/무료숙박권 사용
```
마이페이지 바우처 '사용하기' → 가용 캘린더(불가일 비활성) → 예약 적용 → 완료
   [예외] 적용 조건 불충족 → 사유 안내
```

### Flow 4 — 다이닝 예약
```
다이닝 목록 → 레스토랑 → 날짜·시간·인원 → 좌석 예약(외부 API) → 확정/리마인더
   [예외] 가용 슬롯 없음 / 외부 API 오류 → 재시도
```

## 4. 상태 원칙
- 모든 목록·검색·예약 화면: 빈/로딩(스켈레톤)/오류(재시도)/권한(로그인 유도) 정의.
- 전환 지점(검색→상세→예약→결제) 이탈 최소화: Step 축소·Sticky CTA·진행 표시.
