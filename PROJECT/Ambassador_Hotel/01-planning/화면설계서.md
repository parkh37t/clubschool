## A. 다이닝 예약 (FNR-06)
### A-1 레스토랑 목록
| 항목 | 내용 |
| --- | --- |
| 목적/진입 | 다이닝 메뉴 → 호텔별 레스토랑 목록 |
| 표시 | 레스토랑 카드(메뉴·운영시간·위치·대표이미지) |
| 액션→결과 | 카드 tap → A-2 상세/예약 |
| 상태 | 로딩(스켈레톤)·빈("운영 중 레스토랑 없음")·오류(재시도) |
| 정책 | 운영시간 외 표기, 휴무 배지 |

### A-2 다이닝 예약 신청·확인
| 항목 | 내용 |
| --- | --- |
| 목적/진입 | 날짜·시간·인원 선택 후 좌석 예약(외부 API 연계) |
| 표시 | 가용 시간 슬롯, 좌석/룸, 요청사항 |
| 액션→결과 | [예약 신청]→확정→마이페이지 등록 / 예약 확인·취소 |
| 상태 | 로딩(가용 조회)·빈(가용 슬롯 없음)·오류(외부 API 실패→재시도)·권한(비로그인→로그인 유도) |
| 정책 | 취소 정책 표시, 확정/취소/리마인더 푸시(1시간 전) |

| --- | --- |
| 표시 | 목록(검색·필터·페이지네이션), 상세/편집 |
| 액션 | 상태변경·강제탈퇴·휴면(회원) / 등록·수정·삭제·노출(숙소) / 취소·환불승인(예약) / 생성·일괄배포(쿠폰) |
| 상태 | 로딩·빈·오류·권한 / 저장 실패 롤백 |
| 정책 | 변경 이력 로깅, 위험 액션 확인 다이얼로그 |

| 항목 | 내용 |
| --- | --- |
| 표시 | 에디터(볼드/색상/표), 이미지 업로드(표준 사이즈/WebP), 클리닝 도구(중복·불일치 목록) |
| 액션 | 편집 저장, 표준화 적용, 클리닝 1회성+상시 |
| 상태 | 로딩·빈·오류·미저장 경고 |
| 정책 | 이미지 표준 가이드, 조회수 표시(FNR-7-9), 비번 변경 시 OTP(FNR-7-10) |
