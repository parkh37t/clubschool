# 다국어 텍스트 스펙 — i-ONE Bank Global (Mobile)

> 담당: 차도안(제품 UI) · skill: `design-system-build`
> 목적: 다국어 가변 텍스트로 인한 컴포넌트 레이아웃 깨짐 방지
> 기준 폭: 375px (iPhone SE 기준) · 콘텐츠 영역: 375 − 32(좌우 패딩 각 16) = **343px**
> 지원 언어: 영어(기준) / 베트남어 / 중국어 간체 — [추측: 확인 필요]
> 작성일: 2026-06-21

---

## 0. 읽는 법

- **최소(min)**: 이보다 짧을 경우 레이아웃이 어색하거나 오른쪽 공백 과다
- **권장(rec)**: 번역 시 목표 범위
- **최대(max)**: 이 초과 시 truncation 또는 wrap 규칙 적용
- 문자수는 **화면 표시 기준(렌더 단위 글자 수)**이며 언어별 글자당 픽셀 폭은 다름 (항목별 설명)
- 토큰 참조: 간격 `--space-1(4px)` ~ `--space-6(24px)`, 반경 `--r-sm(8)·md(12)·lg(16)·pill(999)`, 타이포 `title 20/700 · section 16/600 · body 14/400 · caption 12/400`

## 1. AppBar title

### 레이아웃 구조

```
[ ← back 44px ][ title flex:1 ][ icon 44px ]
총 AppBar 폭 375px, 좌우 패딩 --space-4(16px) 포함
title 가용 폭 ≈ 375 − 16×2 − 44×2 = 255px
```

### 텍스트 길이 규칙

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 최소 | 2자 | 단독 화면 코드(예: "EN") — [추측: 최소 케이스 미확정] |
| 권장 | 10–18자 | 영어 기준 1줄 내 표시 가능 |
| 최대 | 24자 | 이 초과 시 truncation |

### truncation vs wrap

- **규칙: truncation (`text-overflow: ellipsis`, 단일 행 고정)**
- AppBar는 고정 높이(52px min-height)를 유지해야 하므로 줄바꿈 불허
- 말줄임(…) 위치: 텍스트 우측 끝

### 언어별 케이스

| 언어 | 예시 텍스트 | 예상 렌더 폭 | 처리 |
| --- | --- | --- | --- |
| 영어 | "Certificate Management" (23자) | ≈ 170px | 정상 표시 |
| 베트남어 | "Quản lý giấy tờ chứng nhận" (28자) | ≈ 230px | 24자 초과 → truncation |
| 중국어 간체 | "证件管理" (4자) | ≈ 64px (한자 폭 넓음) | 정상 표시 |

### 아이콘+텍스트 정렬 규칙

- title은 `flex: 1`로 좌우 아이콘 버튼 사이 공간을 차지
- 아이콘이 없는 홈 화면(home variant): back 버튼 없이 brand 텍스트 + 우측 lang 버튼
- 줄바꿈 금지 → title 요소에 `white-space: nowrap; overflow: hidden; text-overflow: ellipsis`

## 2. Button

### 레이아웃 구조

```
[ gap:8px ][ (icon 선택) ][ label ]
기본 폭: width:100% (BottomCTA 내부 또는 본문 전폭)
dual 배치 시: (343 − --space-2) / 2 ≈ 167px 각
min-height: 48px (터치 타깃 보장)
```

### 텍스트 길이 규칙

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 최소 | 2자 | "OK", "확인" 등 |
| 권장 | 4–16자 | 1줄 표시, 여백 균형 |
| 최대 (single 폭) | 28자 | 전폭(343px) 기준, font-size 14px |
| 최대 (dual 폭) | 14자 | 167px 기준 |

### truncation vs wrap

- **규칙: wrap 허용, 단 2줄 이내**
- 버튼 min-height:48px → 2줄 랩 시 자동 높이 증가, **최대 72px**까지만 허용
- 2줄 초과 시 truncation 처리 (3줄 이상 버튼은 UX 문제로 기획 재협의)
- dual 버튼에서 한쪽이 2줄이면 양쪽 높이 동일하게 맞춤 (`align-items: stretch`)

### 언어별 케이스

| 언어 | 예시 | single 처리 | dual 처리 |
| --- | --- | --- | --- |
| 영어 | "Download Certificate" (20자) | 정상 1줄 | 2줄 wrap |
| 베트남어 | "Tải xuống giấy chứng nhận" (26자) | 1줄(간당간당) | 2줄 wrap |
| 중국어 간체 | "下载证书" (4자) | 정상 1줄 | 정상 1줄 |

### 아이콘+텍스트 정렬 규칙

- 아이콘(20×20px) + gap 8px + 텍스트: `display:inline-flex; align-items:center`
- 텍스트 2줄 wrap 시 아이콘은 **첫 줄 수직 중앙** 유지 (`align-self: flex-start; margin-top: 3px`)
- 아이콘 없이 텍스트만인 경우 `justify-content: center`

## 3. ListItem

### 레이아웃 구조

```
[ icon/flag 40px ][ .grow flex:1 ][ chev 20px ]
좌우 패딩 --space-4(16px), gap --space-3(12px)
텍스트 가용 폭 = 343 − 40 − 12 − 20 − 12 = 259px (icon+chev 모두 있을 때)
min-height: 56px
```

### 텍스트 길이 규칙

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 최소 (title) | 2자 | 국가 코드 등 |
| 권장 (title) | 6–20자 | 메뉴명/국가명 1줄 |
| 최대 (title) | 30자 | 이 초과 시 truncation |
| subtitle/caption | 권장 16–28자 | 2줄 허용 |

### truncation vs wrap

- **title(main label): truncation (단일 행)**
- **subtitle/secondary: wrap, 최대 2줄**
- subtitle 2줄 랩 시 ListItem 높이는 `min-height:56px` → 자동 증가 허용 (최대 80px)

### 언어별 케이스

| 언어 | title 예시 | 처리 |
| --- | --- | --- |
| 영어 | "Customer Service Center" (23자) | 정상 또는 truncation |
| 베트남어 | "Trung tâm dịch vụ khách hàng" (30자) | 최대치 → truncation |
| 중국어 간체 | "客户服务中心" (7자) | 정상 표시 |

### 아이콘+텍스트 정렬 규칙

- 아이콘(40×40px)은 `flex-shrink:0` — 텍스트가 길어도 아이콘 크기 불변
- `.grow` 내부 title + subtitle 세로 stack: `display:flex; flex-direction:column; gap:2px`
- chev(›) 아이콘은 `align-self:center` 고정 — 텍스트 줄수와 무관하게 수직 중앙

## 4. CertCard name

### 레이아웃 구조

```
[ .ico 40px ][ .name + badge 행 / description ][ (우측 버튼 선택) ]
가용 폭 = 343 − 40 − --space-3(12) − (우측버튼 있으면 −72) ≈ 219–291px
gap: --space-3(12px), 카드 패딩 --space-4(16px)
```

### 텍스트 길이 규칙

| 항목 | 값 | 비고 |
| --- | --- | --- |
| name 최소 | 4자 | |
| name 권장 | 10–24자 | 1줄 표시 목표 |
| name 최대 | 32자 | 이 초과 시 2줄 wrap |
| description | 권장 20–40자 | 2줄까지 허용 |

### truncation vs wrap

- **name: wrap, 최대 2줄** (증명서 정식 명칭은 생략 불가)
- name 2줄 wrap 시 `.ico`는 첫 줄 top-align (`align-self: flex-start`)
- **description: wrap, 최대 2줄 후 truncation**
- badge는 name 옆 inline 배치, 줄바꿈 시 name 아래 별도 행으로 내려감

### 언어별 케이스

| 언어 | name 예시 | 처리 |
| --- | --- | --- |
| 영어 | "Certificate of Alien Registration" (34자) | 2줄 wrap |
| 베트남어 | "Giấy chứng nhận đăng ký người nước ngoài" (41자) | 2줄 wrap, 초과 truncation |
| 중국어 간체 | "外国人登记证" (7자) | 정상 1줄 |

### badge 배치 규칙

- badge: `font-size:11px; padding:2px 8px; border-radius:var(--r-pill)`
- name과 같은 행에서 `flex-wrap:wrap; gap:4px`로 배치
- name이 2줄인 경우 badge는 name 아래 독립 행에 표시
- badge 텍스트: 최대 8자 (상태어 — "Available", "Expired" 등) — [추측: 확인 필요]

## 5. BottomCTA

### 레이아웃 구조

```
position:sticky; bottom:0
패딩: --space-3(12px) 상하, --space-4(16px) 좌우
gap: --space-2(8px)
single: Button 전폭 343px
dual: Button 각 (343 − 8) / 2 ≈ 167px
```

### 텍스트 길이 규칙

| variant | 최소 | 권장 | 최대 |
| --- | --- | --- | --- |
| single | 2자 | 4–18자 | 26자 |
| dual (각 버튼) | 2자 | 4–12자 | 16자 |

### truncation vs wrap

- **규칙: wrap, 최대 2줄** (Button 규칙과 동일)
- single 2줄 wrap: BottomCTA 영역 높이 증가 → 콘텐츠 스크롤 영역 자동 축소(sticky 동작)
- dual에서 한쪽 2줄 wrap: 양 버튼 높이 동일(`align-items:stretch`), 최대 72px

### 언어별 케이스

| 언어 | dual 예시(좌/우) | 처리 |
| --- | --- | --- |
| 영어 | "Cancel" / "Download" | 정상 1줄 |
| 베트남어 | "Hủy bỏ" / "Tải xuống" | 정상 1줄 또는 2줄 |
| 중국어 간체 | "取消" / "下载" | 정상 1줄 (한자 짧음) |

### 터치 타깃 유지

- 버튼 min-height: **48px** 유지 (텍스트 줄수와 무관)
- 2줄 wrap 시 높이 증가는 허용, **48px 미만으로 내려가는 것 금지**
- BottomCTA 배경 `--surface` + `border-top:1px solid --border` — 스크롤 콘텐츠 가림 방지

## 7. Tabs

### 레이아웃 구조

```
display:flex; border-bottom:1px solid --border
각 탭: flex:1; min-height:44px; padding:--space-3(12px) 0
2탭 기준 각 폭 = 343 / 2 ≈ 171px
3탭 기준 각 폭 = 343 / 3 ≈ 114px
font-size: 14px (body 토큰)
```

### 텍스트 길이 규칙

| 탭 수 | 최소 | 권장 | 최대 |
| --- | --- | --- | --- |
| 2탭 | 2자 | 4–14자 | 18자 |
| 3탭 | 2자 | 3–9자 | 12자 |

### truncation vs wrap

- **규칙: truncation (단일 행 고정)**
- 탭 레이블 2줄 불허 — 탭 높이 44px 고정 (터치 타깃 기준)
- 말줄임 발생 시 번역 재협의 권장 (탭 레이블은 핵심 단어로 축약)

### 언어별 케이스

| 언어 | 예시 (2탭) | 처리 |
| --- | --- | --- |
| 영어 | "Available" / "Owned" | 정상 |
| 베트남어 | "Có thể nhận" / "Đã nhận" | "Có thể nhận"(12자) → 2탭 내 표시 가능, 3탭 시 truncation |
| 중국어 간체 | "可领取" / "已领取" | 정상 (각 3자) |

### 아이콘+텍스트 정렬 규칙

- 탭에 아이콘 사용 시: `display:flex; align-items:center; gap:--space-2(8px); justify-content:center`
- 아이콘 크기: 16×16px (탭 내부 소형)
- 텍스트 truncation 시 아이콘은 유지 — 텍스트 영역만 축소 (`overflow:hidden; text-overflow:ellipsis`)

## 8. 언어별 가변 폭 종합 기준

### 언어 특성 요약

| 언어 | 문자당 평균 폭 (14px Inter 기준) | 단어 길이 특성 | 위험도 |
| --- | --- | --- | --- |
| 영어(기준) | 7–9px | 보통 | 기준 |
| 베트남어 | 6–8px (성조 부호 포함) | 길고 공백 단위 줄바꿈 | **높음** — 단어가 길어 긴 연속 문자열 발생 |
| 중국어 간체 | 14px (정방형 한자) | 짧음, 어절 없음 | 낮음 — 글자수 적으나 px 폭은 넓음 |

> [추측: 독일어·아랍어·태국어 등 추가 언어 확정 시 이 표 업데이트 필요. 독일어 긴 복합명사(예: Aufenthaltsgenehmigung 21자)는 AppBar/Badge에서 특히 위험.]

### 핵심 위험 시나리오

| 시나리오 | 영향 컴포넌트 | 대응 |
| --- | --- | --- |
| 베트남어 긴 단어가 단일 행 내 overflow | Button, CertCard name, Badge | `overflow-wrap: break-word` 적용 |
| 중국어 짧은 텍스트로 버튼 양옆 과다 공백 | Button (dual) | `min-width` 보장, `justify-content:center` |
| 탭 레이블 수 × 언어 길이 → 넘침 | Tabs | truncation 강제 + 번역 축약 가이드 |
| 베트남어 BottomCTA dual 2줄 wrap 불일치 | BottomCTA | `align-items:stretch` 강제 적용 |

## 9. 전역 CSS 보완 규칙

디자인시스템 토큰을 기반으로 아래 규칙을 `styles.css`에 추가 적용한다.

```css
/* 다국어 텍스트 overflow 방지 — 단어 단위 줄바꿈 허용 */
.cert .name,
.listitem .grow,
.btn {
  overflow-wrap: break-word;
  word-break: break-word; /* 베트남어 장음절 대응 */
}

/* truncation 유틸 — AppBar title, Tabs, Badge */
.text-truncate {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

/* Badge 최대폭 */
.badge {
  max-width: 96px; /* [추측: 언어 확정 후 측정값으로 교체] */
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}

/* dual 버튼 높이 동기화 */
.bottomcta {
  align-items: stretch;
}
.bottomcta .btn {
  min-height: 48px; /* 터치 타깃 보장 */
}
```

## 10. 접근성 체크리스트 (다국어 관련)

| 항목 | 기준 | 비고 |
| --- | --- | --- |
| truncation 발생 시 전체 텍스트 접근 | `title` 속성 또는 `aria-label` 제공 | 스크린리더 대응 |
| 줄바꿈으로 높이 변경 시 터치 타깃 | 최소 44×44px 유지 | 디자인시스템 기준 |
| 텍스트 대비 | 본문 ≥ 4.5:1, 대형(18px+) ≥ 3:1 | 다국어 폰트 동일 기준 |
| 폰트 패밀리 다국어 지원 | Inter·Pretendard → CJK는 시스템 폰트 fallback | `system-ui, -apple-system` |
| 베트남어 성조 부호 클리핑 | line-height ≥ 1.5 유지 | 부호 잘림 방지 |
