# 브랜드 가이드 (BX) — i-ONE Bank Global

> 담당: 오색감(BX/브랜드) · skill: `brand-guideline`
> ⚠️ IBK 정확한 브랜드 HEX는 비공개 → 아래 값은 **[추측: IBK 블루 계열 근사치]**. 실제 적용 전 BI 가이드 확인 필요.

## 1. 브랜드 전략
- 미션: 국내거주 외국인이 **언어 장벽 없이** 금융·행정 생활을 해결.
- 전달 감정: 신뢰(은행) · 명료(쉬움) · 환대(글로벌·포용).

## 2. 콘셉트 키워드
`Trustworthy(신뢰)` · `Clear(명료)` · `Global/Welcoming(포용)` · `Effortless(간편)`

## 3. 컬러 시스템 (토큰 매핑 — 디자인시스템과 1:1)
| 토큰 | HEX [추측] | 용도 |
| --- | --- | --- |
| `--ibk-blue` (primary) | `#0A4DA2` | 주요 액션·브랜드 |
| `--ibk-blue-dark` | `#073A7A` | hover/press |
| `--ibk-sky` (accent) | `#1E9BE6` | 보조 강조·아이콘 |
| `--success` | `#1FA463` | 완료/발급 성공 |
| `--warning` | `#E0930B` | 운영시간 외·만료 |
| `--danger` | `#D64545` | 인증 실패/오류 |
| `--fg` / `--fg-muted` | `#1A1F2B` / `#5A6473` | 본문/보조 텍스트 |
| `--bg` / `--surface` | `#F4F6FA` / `#FFFFFF` | 배경/카드 |
| `--border` | `#E2E7EF` | 구분선 |

- 대비: primary(#0A4DA2) on white ≈ 8.6:1 (WCAG AAA 본문 통과). danger/warning은 텍스트
  대비 확보 위해 어두운 톤 사용.

## 4. 타이포 위계
- 영문 우선(외국인 대상): system UI / `Inter` 계열, 한글 병기 시 `Pretendard` **[추측]**.
| 레벨 | 크기/두께 | 용도 |
| --- | --- | --- |
| Title | 20 / 700 | 화면 타이틀 |
| Section | 16 / 600 | 섹션/카드 제목 |
| Body | 14 / 400 | 본문 |
| Caption | 12 / 400 | 보조/날짜 |

## 5. 로고/모티프
- i-ONE Bank Global 워드마크 + IBK 심볼(좌상단). 단독 사용 시 여백 = 심볼 높이 0.5x. **[추측 규정]**
- 모티프: 라운드(반경 12~16px) + 카드 그림자 최소 → 금융앱 신뢰·정돈 인상.

## 6. 톤앤매너 (보이스, 영어 1차)
- do: 짧고 명확한 지시("Issue your wallet"), 안내적·환대적.
- don't: 금융 전문용어 남발, 한국어 전용 표현 직역.
