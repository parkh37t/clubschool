## 3. 상태별 UI 규칙 (필수)
- **로딩**: 스켈레톤 또는 spinner + 비활성 CTA.
- **빈(empty)**: 일러스트/아이콘 + 한 줄 안내 + 1개 CTA.
- **오류(error)**: 원인 메시지 + [재시도] (네트워크/기관점검/인증실패 구분 문구).
- **비활성(disabled)**: 약관 미동의·필수 미입력 시 CTA disabled + 보조 안내.
- 같은 의미 = 같은 토큰: 성공=`--success`, 경고/만료=`--warning`, 오류/실패=`--danger`.

## 4. 접근성 기준(차도안→이풍뎅 전달)
- 최소 터치 타깃 44×44px, 본문 대비 ≥4.5:1, 색+아이콘/텍스트 병행.
- 직통연결/다운로드/제출 등 아이콘 버튼은 접근명 필수.
