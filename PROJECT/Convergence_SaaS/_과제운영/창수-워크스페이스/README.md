## 작업 사이클 (산출물 1건당)
1. 팀이 이 폴더에 **템플릿**을 둔다(S6는 이미 제공).
2. 창수가 `[작성]` 표시 부분을 채운다(조사·판단 포함).
3. 본인 이름으로 커밋:
   ```bash
   git config user.name "창수(Troy)"; git config user.email "troy@example.com"   # 최초 1회
   git commit --author="창수(Troy) <troy@example.com>" -m "Feat: 리서치 가이드 v1 (창수)"
   ```
   (페어작업이면 커밋 메시지 하단에 `Co-authored-by: 창수(Troy) <troy@example.com>`)
4. 팀 리뷰(정우선/나기획/한도전) → 피드백 → 보완 → **사인오프**를 `경력증빙_템플릿.md`에 기록.
