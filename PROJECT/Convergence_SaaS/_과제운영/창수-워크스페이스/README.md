## 작업 사이클 (산출물 1건당)
1. 팀이 이 폴더에 **템플릿**을 둔다(S6는 이미 제공).
2. 창수가 `[작성]` 표시 부분을 채운다(조사·판단 포함).
3. 본인 이름으로 커밋 (계정 `troyk0725@gmail.com`):
   ```bash
   git commit --author="Troy(창수) <troyk0725@gmail.com>" -m "Feat: 리서치 가이드 v1 (창수)"
   # 본인 로컬 환경이면 최초 1회: git config user.name "Troy"; git config user.email "troyk0725@gmail.com"
   ```
   (페어작업이면 커밋 메시지 하단에 `Co-authored-by: Troy(창수) <troyk0725@gmail.com>`)
4. 팀 리뷰(정우선/나기획/한도전) → 피드백 → 보완 → **사인오프**를 `경력증빙_템플릿.md`에 기록.
