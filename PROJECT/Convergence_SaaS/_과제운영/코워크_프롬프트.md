> 사용법: 클로드 코워크에 `Converge_통합핸드오프_전체포함.md`를 **첨부**하면서 아래 코드블록을 **그대로 복사**해 붙여넣는다.
> 이중 목표(제품 진전 A + 창수 성장 B)를 명시해, 코워크가 실물 품질로 만들면서 창수를 주인공으로 세우게 한다.

```text

# 프로젝트
"Converge" — 사내 실적관리 도구 con-mgt(vanilla JS + Express + PostgreSQL JSONB, 라이브 운영)를
여러 회사가 쓰는 멀티테넌트 SaaS로 서비스화하는 과제. 그 하위로 창수(Troy)의 "Global-Ready"
(AI를 페어로 영문 i18n을 기획·설계·개발) 과제가 있어.

# 이 파일 구조
- 맨 앞 목차 → ①~⑬ 팀 산출물(이어서 일할 컨텍스트) + 부록 A~G(con-mgt 실물 원본, 깊은 참조).
- 먼저 "① 핸드오프 지도"를 읽으면 SSOT·완료물·다음 액션·전제가 다 정리돼 있어.
  파일이 크니 목차 → ① → 필요한 섹션 순으로 읽어.

# 꼭 지킬 전제
- 상품화 실제 대상은 con-mgt. 이 저장소의 clubschool(React)은 별개 참고 코드.
  (앞 문서의 "M0 버그"는 clubschool 것 → con-mgt엔 해당 없음)
- con-mgt 원본(부록)은 실 인프라 서술 포함 → 외부 공유·유출 금지.

# 목표 (이중 목표 — 둘을 동시에)
(A) 제품 목표: Converge를 실제로 영문/글로벌 대응 가능하게 만드는 "진짜" 산출물
    (한↔영 용어집·i18n 설계·다국어 동작 코드)을 남긴다. 연습이 아니라 제품에 반영 가능한 품질로.
(B) 창수 성장: 창수(Troy)가 AI를 페어로 이 일을 "직접" 수행하며 경력 증빙(D7)을 쌓게 한다.
    → 네가 대신 다 하지 말고, 초안·옵션·리뷰로 창수를 이끌어라(코칭+페어).

# 진행 순서
D1 용어집 검수(⚠ 오역위험어 12개부터) → D2 i18n 설계 → D4 다국어 슬라이스 개발
 → D6 AI 활용 플레이북·D7 경력증빙은 병행해서 채운다.

# 너에게 바라는 것
1. 먼저 전체를 읽고, 이해한 프로젝트 상태를 5~10줄로 요약해 줘(내가 맞게 넘어왔는지 확인용).
2. 위 이중 목표를 위한 진행 계획을 먼저 제안해 줘. 바로 실행하지 말고 계획부터.
3. 산출물은 원본 용어·구조와 일관되게, 결과는 한국어로. 커밋은 창수 이름(troyk0725@gmail.com)으로.
```
