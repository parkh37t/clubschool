# 제품 전략 — i-ONE Bank Global: 전자지갑 & 외국인 고객센터

> 담당: 정우선(PO) · skill: `product-strategy` · 입력: `00-sales/RFP-분석.md`

## 1. 문제 정의
국내 거주 외국인은 행정·공공 증명서(거소신고·외국인등록·출입국·여권정보) 발급을 위해
정부24 등 한국어 중심 채널을 써야 해 **언어·접근성 장벽**이 크다. 또한 문제 발생 시
**한국어 고객센터**에 가로막힌다. → i-ONE Bank Global 안에서 **다국어로 증명서 발급·보관·제출**과
**언어별 고객센터 직통연결**을 제공해 외국인 금융·생활 경험의 단절을 없앤다.

## 2. 대상 사용자 / 가치
| 사용자 | 핵심 과업(Job) | 사용자 가치 |
| --- | --- | --- |
| 국내거주 외국인(주) | 증명서 발급·보관·제출, 고객센터 연결 | 모국어로 한 곳에서 처리 |
| 외국인 신규 고객 **[추측]** | 가입 유인 | 생활밀착 서비스로 앱 체류·전환 |

- 비즈니스 목표 연결: 외국인 비대면 채널 경쟁력 강화 → 신규 고객 확보(RFP 기대효과와 일치).

## 3. MVP 범위 (1단계 프로토타입 기준)
### 포함 (In)
- 전자지갑 **발급**(인증 → 약관 → 발급 완료)
- 증명서 **신청가능목록** 조회 → **신청·인증** → **신청 완료** (RFP 거래 예시 3스텝)
- **증명서 보관함**: 목록 / 상세 **열람·다운·제출**
- **고객센터**: 메인 진입 아이콘 → **언어(국가)별 연락처·직통연결** 화면
- 다국어 **프레임**(1차 영어 기준, 리소스 토큰화로 확장 슬롯)
- 인증수단 **공동/IBK인증서**, 미보유 시 **예외 안내** 플로우

### 제외 (Out, 차기)
- 전자문서지갑 **정보변경/폐기**, 주소조회/복사/**공유**, 보낸/받은 내역 상세 (메뉴 자리만 노출)
- 실제 정부24·유통시스템 연동(프로토타입은 **mock 데이터/스텁**) **[추측 규격]**
- 풀 다국어 번역(영어 외 언어는 placeholder)
