## 1. 정보구조 (IA)
```
i-ONE Bank Global (Home)
├─ [상단] 언어 선택 (Language)
├─ [상단 작은 아이콘] 고객센터 (Customer Center)   ← SFR-062
│   └─ 언어(국가)별 고객센터
│       └─ 국가 항목: 전화 연락처 · 직통연결(call) 아이콘
└─ [메뉴] 전자지갑 (Digital Wallet)                ← SFR-063
    ├─ 지갑 발급 (Issue Wallet)  [미발급 사용자 최초 1회]
    ├─ 증명서 신청 (Request Certificate)
    │   ├─ ① 신청가능목록 (Available list)
    │   ├─ ② 신청·인증 (Request & Auth)
    │   └─ ③ 신청 완료 (Done)
    ├─ 증명서 보관함 (My Certificates)
    │   └─ 증명서 상세 → 열람 / 다운로드 / 제출(Submit)
    └─ 지갑 관리 (Manage) [P2 stub: 정보변경·폐기·공유·내역]
```

## 2. 핵심 사용자 플로우

### Flow A — 전자지갑 발급 (최초)
```
Home → 전자지갑 진입
 → [분기] 지갑 보유?
    ├ 미보유 → 지갑 발급 안내 → 인증(공동/IBK) → 약관 동의 → 발급 완료 → 지갑 홈
    │           └ [예외] 인증서 미보유 → "인증서 발급 안내" → 종료/외부안내
    └ 보유 → 지갑 홈
```

### Flow B — 증명서 신청 (RFP 거래 예시 3스텝)
```
지갑 홈 → ① 신청가능목록(4종) → 증명서 선택
 → ② 신청·인증 (수령방법/약관 → 인증 OTP/인증서)
 → ③ 신청 완료 (신청정보·접수번호) → [보관함에서 확인] CTA
    [예외] 인증 실패 → 재시도 / 신청 불가 사유 안내
    [예외] 발급기관 점검 → 빈/오류 상태 안내
```

### Flow C — 증명서 활용 (보관함)
```
지갑 홈 → 증명서 보관함
 → [상태] 빈 보관함 → "증명서 신청하기" CTA
 → 증명서 선택 → 상세(열람) → [다운로드 | 제출]
    제출 → 제출 대상 선택 → 제출 완료
```

### Flow D — 고객센터 직통연결 (SFR-062)
```
Home 상단 고객센터 아이콘 → 언어별 고객센터
 → 국가/언어 선택 → 연락처 표시 + [직통연결] 아이콘 tap → 전화 연결(tel:)
    [예외] 운영시간 외 → 운영시간 안내 + 콜백/이메일 대안
```

## 4. 정책 메모
- 인증수단: 공동인증서·IBK인증서만(금융인증서 불가) — S1/S4 공통.
- 다국어: 모든 텍스트는 리소스 키로(하드코딩 금지). 1차 en, 확장 슬롯.
- 접근성: 직통연결은 `tel:` 링크 + 명시적 라벨, 키보드/스크린리더 대응(이풍뎅 게이트).
