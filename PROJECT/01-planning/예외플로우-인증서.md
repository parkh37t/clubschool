# 예외 플로우 정의서 — 인증/증명서 (컨버전스1팀 A4)

> 담당: 나기획 · skill: `service-planning`
> 연관 화면: S1(전자지갑 발급) · S4(신청·인증) · S7(증명서 상세)
> 원칙: 외국인 UX 우선. 영어 안내 문구 1차. 정책 미확정 수치는 **[추측]+확인필요** 표기.
> 작성일: 2026-06-21

---

## 개요

인증/증명서 관련 예외는 외국인 사용자가 이탈하는 최대 병목 구간이다.
아래 5종 예외 각각에 대해 **트리거 조건 → 화면/상태 → 안내 문구 → 복구·대안 경로**를
완결 정의한다. 모든 예외 상태는 S1·S4·S7 화면설계서 정책·예외 항목과 정합한다.

## 예외 1. 인증서 미보유

### 트리거 조건

| 조건 | 상세 |
| --- | --- |
| 공동인증서 없음 | 사용자 기기에 공동인증서 파일이 없거나 조회 결과 0건 |
| IBK 인증서 없음 | IBK i-ONE Bank 자체 인증서 미등록 상태 |
| 두 수단 모두 없음 | 위 두 조건이 동시에 충족될 때 예외 진입 |

### 플로우

```
S1 [발급하기] 탭
  └→ 인증수단 조회
       ├→ (어느 하나라도 있음) → 인증 진행 (정상 플로우)
       └→ (둘 다 없음) → [예외1] 인증서 미보유 화면
                              ├→ [외부 발급 안내 보기] → 외부 가이드 바텀시트
                              └→ [나중에 하기] → S0 홈으로 이동 (중단)
```

### 화면 상태

| 상태 | 표시 방식 |
| --- | --- |
| 로딩 | 인증수단 조회 중 스켈레톤 + 스피너 (0.5s **[추측]**)  |
| 오류(미보유) | 인라인 오류 배너. 발급하기 버튼 비활성 |
| 빈 | 해당 없음 (인증수단 0건은 오류 상태로 처리) |

### 사용자 안내 문구 (영어 1차)

```
[제목]   No Certificate Found
[본문]   To issue your digital wallet, a Korean digital certificate
         (Gongdong or IBK certificate) is required.
         You currently have no registered certificate.
[버튼1]  How to Get a Certificate  →  외부 가이드
[버튼2]  Maybe Later               →  홈(S0)
```

> 한국어 보조 문구(병기): "공동인증서 또는 IBK 인증서가 필요합니다."

### 외부 발급 가이드 바텀시트

| 항목 | 내용 |
| --- | --- |
| 목적 | 인증서 발급 방법 안내. 앱 이탈 최소화를 위해 바텀시트 내 표시 |
| 공동인증서 | 은행/증권사 앱에서 발급. 외부 링크(금융결제원 안내 페이지) **[URL 확인필요]** |
| IBK 인증서 | IBK i-ONE Bank 앱 내 인증센터 → 인증서 발급. 딥링크 또는 앱 이동 안내 **[딥링크 스킴 확인필요]** |
| 닫기 | 바텀시트 닫기 → 미보유 화면 유지 |

### 복구·대안 경로

| 경로 | 조건 |
| --- | --- |
| 인증서 발급 후 재시도 | 사용자가 외부 앱에서 발급 완료 후 돌아와 [발급하기] 재탭 |
| 중단(나중에 하기) | S0 홈 이동. 전자지갑 미발급 상태 유지 |
| 고객센터 | 바텀시트 하단 고객센터 링크 → S8 고객센터 화면 |

### 정합: S1 화면설계서

> S1 정책·예외: "인증서 미보유→'인증서 발급 안내' 화면(외부), 발급 중단" — 본 예외1이 해당 정책을 구체화.

## 예외 2. 인증 실패(N회 초과)

### 트리거 조건

| 조건 | 상세 |
| --- | --- |
| 인증 실패 1회 | 비밀번호/PIN 불일치, 인증서 오류 등 |
| 인증 실패 누적 | 연속 N회 실패 시 차단 정책 진입 |
| 적용 화면 | S1(발급 인증) · S4(신청 인증) 공통 |

> **[추측]+확인필요** N = 5회 (금융권 일반 관행 기준 추정). 실제 IBK 정책 확인 후 값 확정.

### 플로우

```
인증 시도
  └→ 인증 SDK/API 응답
       ├→ 성공 → 정상 플로우
       ├→ 실패 (1회 ~ N-1회)
       │    └→ 실패 배너 + 잔여 횟수 표시 + [재시도] 버튼 활성
       └→ 실패 (N회 누적)
            └→ 차단 화면(모달 또는 전체 화면)
                 ├→ [잠금 해제 방법 안내] → 고객센터(S8) 또는 IBK 지점 안내
                 └→ [홈으로] → S0
```

### 화면 상태

| 단계 | 상태 | 표시 방식 |
| --- | --- | --- |
| 1회 ~ N-1회 실패 | 오류 | 인라인 배너(빨간색). 잔여 시도 횟수 카운터 표시 |
| N회 실패(차단) | 차단 오류 | 전체화면 오버레이 또는 모달. 재시도 버튼 숨김 |
| 잠금 해제 처리 중 | 로딩 | 고객센터 연결 시 로딩 스피너 |

### 사용자 안내 문구 (영어 1차)

**실패 1회 ~ N-1회:**
```
[배너]  Authentication failed. Please check your certificate password.
        (N-[현재실패횟수]) attempt(s) remaining.
```

**N회 차단:**
```
[제목]  Authentication Locked
[본문]  You have exceeded the maximum number of authentication attempts.
        Please contact IBK Customer Center or visit a branch to unlock.
[버튼1] Contact Customer Center  →  S8
[버튼2] Go to Home               →  S0
```

> 한국어 보조 문구(병기): "인증 잠금 상태입니다. 고객센터에 문의하세요."

### 복구·대안 경로

| 경로 | 조건 |
| --- | --- |
| 재시도 | N-1회 이하 실패. [재시도] 버튼 노출 |
| 잠금 해제 → 고객센터 | N회 차단 후 S8 경유 고객센터 문의 |
| 잠금 해제 → 지점 방문 | S8 고객센터에서 지점 안내 **[지점 연결 정책 확인필요]** |
| 차단 해제 후 재시도 | 잠금 해제 완료 후 사용자가 앱 재진입 → S1 또는 S4 재시도 |

### 정합: S1·S4 화면설계서

> S4 정책·예외: "인증 3회 실패→차단 안내 [추측 정책]" — 본 예외2에서 N=5로 재추측, 확인필요 표기.
> S1 상태: "오류(인증 실패 메시지)" — 본 예외2 실패 배너가 해당.

## 예외 3. 인증 타임아웃

### 트리거 조건

| 조건 | 상세 |
| --- | --- |
| 사용자 응답 없음 | 인증 화면 진입 후 T초 이내 PIN/비밀번호 미입력 **[추측: T=180초]+확인필요** |
| 인증 SDK 세션 만료 | 외부 인증 SDK가 세션 토큰 만료를 반환 |
| 네트워크 응답 없음 | 인증 요청 후 서버 응답 대기 시간 초과 **[추측: 30초]+확인필요** |

### 플로우

```
인증 화면 진입
  └→ 타임아웃 카운트다운(백그라운드)
       ├→ 시간 내 인증 완료 → 정상 플로우
       └→ T초 경과 또는 SDK 세션 만료
            └→ 타임아웃 모달 팝업
                 ├→ [다시 시도] → 인증 화면 리셋(카운트다운 초기화)
                 └→ [취소]     → 이전 화면(S1 또는 S4) 복귀
```

### 화면 상태

| 상태 | 표시 방식 |
| --- | --- |
| 타임아웃 임박 경고 | 카운트다운 잔여 시간 표시 (T-30초부터 노출) **[추측]+확인필요** |
| 타임아웃 발생 | 모달. 인증 입력 UI 블러 처리 |
| 재시도 진행 | 모달 닫힘 → 인증 화면 리셋 + 로딩 스피너 |

### 사용자 안내 문구 (영어 1차)

**임박 경고:**
```
[배너]  Session expiring in 30 seconds. Please complete authentication.
```

**타임아웃 발생:**
```
[제목]  Session Timed Out
[본문]  Your authentication session has expired.
        Please try again.
[버튼1] Try Again  →  인증 화면 리셋
[버튼2] Cancel     →  이전 화면 복귀
```

> 한국어 보조 문구(병기): "인증 세션이 만료되었습니다. 다시 시도해 주세요."

### 복구·대안 경로

| 경로 | 조건 |
| --- | --- |
| 즉시 재시도 | [다시 시도] 탭 → 인증 카운트 리셋, 실패 횟수 누적 없음 (타임아웃은 실패 횟수에 미산입) **[확인필요]** |
| 이전 화면 복귀 | [취소] 탭 → S1 발급 화면 또는 S4 신청화면으로 복귀. 입력 데이터 유지 |
| 반복 타임아웃 시 | 2회 연속 타임아웃 후 고객센터 링크 노출 **[추측]+확인필요** |

### 정합: S4 화면설계서

> S4 상태: "오류(인증 실패→재시도, 타임아웃, 신청불가 사유)" — 본 예외3이 타임아웃 분기를 구체화.

## 예외 4. 발급기관 점검/오류

### 트리거 조건

| 조건 | 상세 |
| --- | --- |
| 발급기관 점검 중 | 외부 기관(출입국·외국인청, 정부24 등) 서버 점검 응답 반환 |
| 발급기관 오류 | HTTP 5xx 또는 기관 자체 오류 코드 반환 |
| 목록 조회 실패 | S3 증명서 목록 API가 빈 응답 또는 오류 반환 |
| 발급 요청 실패 | S4 신청·인증 후 기관 발급 API 오류 반환 |

### 플로우

```
[S3 목록 조회 시]
앱 → 목록 API 요청
  └→ 응답
       ├→ 정상 목록 → S3 정상 표시
       ├→ 빈 배열   → 빈 상태 ("발급 가능한 증명서가 없습니다")
       └→ 오류/점검 → S3 오류 배너 + [재시도] 버튼

[S4 발급 요청 시]
인증 성공 → 발급 기관 API 호출
  └→ 응답
       ├→ 발급 성공 → S5 완료 화면
       ├→ 점검 중   → 점검 안내 모달
       └→ 기관 오류 → 오류 모달 + [재시도] / [나중에 보기]
```

### 화면 상태

| 화면 | 상태 | 표시 방식 |
| --- | --- | --- |
| S3 목록 | 로딩 | 스켈레톤 카드 3개 |
| S3 목록 | 빈 (발급가능 0건) | 일러스트 + "No certificates available" 안내 문구 |
| S3 목록 | 오류 (기관 점검/오류) | 오류 배너 + [재시도] 버튼 + 마지막 갱신 시각 표시 **[추측]+확인필요** |
| S4 신청 | 로딩 (발급 요청 중) | 전체 로딩 오버레이 + "Requesting certificate…" 문구 |
| S4 신청 | 오류 (기관 점검) | 오류 모달. 입력 데이터 보존 |
| S4 신청 | 오류 (기관 오류) | 오류 모달. 오류 코드 표시 **[코드 체계 확인필요]** |

### 사용자 안내 문구 (영어 1차)

**S3 목록 오류:**
```
[배너]  The issuing authority is currently unavailable.
        Please try again later.
[버튼]  Try Again
```

**S4 점검 중 모달:**
```
[제목]  Service Under Maintenance
[본문]  The certificate issuing service is temporarily unavailable
        for scheduled maintenance. Please try again after a few hours.
[버튼1] Try Again     →  발급 요청 재시도
[버튼2] Go to Home    →  S2 지갑 홈
```

**S4 기관 오류 모달:**
```
[제목]  Request Failed
[본문]  An error occurred while requesting your certificate (Error: [코드]).
        Please try again. If the issue persists, contact IBK Customer Center.
[버튼1] Try Again            →  발급 요청 재시도
[버튼2] Contact Customer Center →  S8
```

> 한국어 보조 문구(병기): "발급기관 서비스 이용이 일시적으로 불가합니다."

### 복구·대안 경로

| 경로 | 조건 |
| --- | --- |
| 즉시 재시도 | [재시도] 탭. 최대 재시도 횟수 **[추측: 3회]+확인필요** |
| 나중에 시도 | S2 지갑 홈 또는 S0 홈으로 이동. 신청 초안 저장 여부 **[확인필요]** |
| 고객센터 문의 | S8 고객센터 화면 연결 |
| 점검 예정 공지 | 사전 점검 일정 있을 경우 S3 화면 상단 배너로 사전 고지 **[운영 정책 확인필요]** |

### 정합: S3·S4 화면설계서

> S3 상태: "오류(발급기관 점검 중 → 재시도)" — 본 예외4가 S3·S4 양쪽 기관 오류를 구체화.

## 예외 5. 증명서 만료

### 트리거 조건

| 조건 | 상세 |
| --- | --- |
| 만료일 경과 | 증명서의 유효기간(expiry date)이 현재 날짜를 초과 |
| 만료 임박 | 만료일 D-7일 이내 **[추측]+확인필요** |
| 제출 시도 | 만료 증명서를 제출하려 할 때 |

### 플로우

```
S6 보관함 → 증명서 카드 탭 → S7 증명서 상세
  └→ 만료 여부 확인
       ├→ 유효 → 정상 상세 표시 (다운로드·제출 활성)
       ├→ 만료 임박 (D-7 이내)
       │    └→ 상단 경고 배너 표시 (상세 기능은 유지)
       └→ 만료됨
            ├→ 만료 배너 표시 (상세 열람은 허용)
            ├→ [다운로드] 버튼: 만료 배지 + 비활성 **[다운로드 허용 여부 확인필요]**
            ├→ [제출] 버튼: 비활성 + 탭 시 차단 토스트
            └→ [재발급 신청] 버튼 노출 → S3 신청가능목록
```

### 화면 상태

| 상태 | 표시 방식 |
| --- | --- |
| 유효 | 정상 상세 화면 (기준 상태) |
| 만료 임박 (D-7 이내) | 상단 황색 배너: "This certificate expires in N days" |
| 만료됨 | 상단 빨간 배너 + 증명서 카드에 만료 배지(EXPIRED) + 제출 버튼 비활성 |
| 재발급 로딩 | [재발급 신청] 탭 후 S3으로 이동 시 로딩 |

### 사용자 안내 문구 (영어 1차)

**만료 임박 배너:**
```
This certificate expires in [N] day(s). Please renew it soon.
```

**만료 배너:**
```
This certificate has expired and cannot be submitted.
Please request a new certificate.
```

**제출 차단 토스트 (만료 증명서 제출 시도):**
```
Expired certificates cannot be submitted. Please request a new certificate.
```

**재발급 버튼:**
