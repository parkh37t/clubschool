## 2. 비즈니스 문제 / 목표 (사실 기반)
- **외부환경**: 고객 중심 디지털 전환 가속, 빅테크·핀테크 진입 → MZ·외국인 등 신규 고객층의
  간편·맞춤형 금융경험 요구.
- **내부환경**: '09년 구축 인터넷뱅킹 기술구조 노후화 → 채널별 중복개발, 개발생산성·확장성·
  인프라 유연성 저하.
- **목표**: 단절 없는(Seamless) 유니버설 뱅킹 기반 + 디지털 플랫폼으로 채널 중복 제거,
  서비스 출시 속도·운영효율·확장성 확보. **i-ONE Bank Global 재구축으로 외국인 고객 경쟁력 강화.**

## 3. 요구사항 분해 — 본 작업 범위(화면 확정분)
> 전체 RFP는 신규요건 18건 중 13/18·14/18만 화면 노출. 본 팀의 설계·프로토타입 범위는
> 화면이 확정된 **SFR-062, SFR-063** 2건으로 한정. 나머지는 범위 외(설계 시 가정 표기).

### SFR-062 — 외국인 전용 고객센터 (기능 요구, 사실)
- 외국인 전용 고객센터 **직통연결 화면 신설**
- 메인화면에 고객센터 직통연결 **작은 아이콘** 신설 → 클릭 시 외국인 상담 담당직원 직통연결
- **언어(국가)별** 고객센터 연결 안내 전용화면, 언어별 연락처·직통연결 아이콘 제공

### SFR-063 — 외국인 전용 전자지갑(전자증명서) (기능 요구, 사실)
- 국내거주 외국인에게 행정·공공기관 민원 발급신청 서비스 제공 (i-ONE Bank Global 내 전자지갑)
- 주요 요건: **공동인증서·IBK인증서만 가능**(금융인증서 불가)
- 발급 가능 증명서(외국인 맞춤 4종): 국내거소신고 사실증명, 외국인등록 사실증명,
  출입국 사실증명, 여권정보증명서 (+ 기타 필요한 증명서 추가 가능)
- 메뉴구성(정부24·전자문서 유통시스템 **API 호출**로 업무처리):
  ① 전자문서지갑 발급 ② 전자문서지갑 정보변경/폐기 ③ 전자문서지갑 관리(주소조회·복사·공유)
  ④ 증명서 보관함 內 증명서 열람·다운·제출 ⑤ 보관함 內 보낸/받은 내역, 신청 내역
- 거래 예시(이미지): ❶ 증명서 신청가능목록 출력 → ❷ 전자증명서 신청·인증 → ❸ 신청 완료
