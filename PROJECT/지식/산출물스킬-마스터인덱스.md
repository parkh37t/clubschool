# Claude 산출물 스킬 — 마스터 인덱스 (팀 상시 학습 지식베이스)

> 목적: 컨버전스1팀이 "무엇을 어떤 도구로 만들 수 있는가"를 한곳에서 학습·갱신.
> 갱신 규칙: 새 스킬/도구를 익히면 이 문서에 추가(주기 회의에서 점검).
> 정책: **Claude Design First + Claude-native Office First** (외부는 보조).

## A. Claude 네이티브 직접 생성 (코드로 — 외부 불필요)
| 산출물 | 방법 | 비고 |
| --- | --- | --- |
| HTML/CSS/JS (Claude Design·프로토타입·슬라이드덱) | 직접 저작 | 비주얼/인터랙션 1순위, SSOT 디자인 |
| Markdown 문서 | 직접 저작 | 스펙 SSOT |
| **PPTX** | `python-pptx` | `_generators/gen_office.py` |
| **DOCX** | `python-docx` | `gen_office.py`, `gen_docs_from_md.py`(md→docx) |
| **XLSX** | `openpyxl` | `gen_office.py` |
| PDF | 브라우저 인쇄(@page) / LibreOffice | 무손실은 브라우저 인쇄; weasyprint·playwright는 egress로 설치 가능 |
| 이미지/차트 | 인라인 SVG, HTML+Recharts | matplotlib 등 egress 설치 가능 |
| 다이어그램(텍스트) | Mermaid(HTML 내) | 편집형은 Figma FigJam |
| 코드(전 언어) | 직접 | — |

> 환경: **egress 활성** → 필요 라이브러리 pip 설치 가능(예: python-pptx/docx/openpyxl 설치 완료).
> 로컬 미설치: 브라우저 엔진(chromium)·wkhtmltopdf. LibreOffice는 설치돼 있음.
