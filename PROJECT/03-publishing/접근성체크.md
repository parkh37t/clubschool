# 접근성 점검 — 전자지갑 & 고객센터 프로토타입

> 담당: 이풍뎅(인터랙션·접근성 심화) · skill: `accessibility-audit` (WCAG 2.1 AA 기준)

## 점검 결과
| 기준 | 결과 | 구현 위치 |
| --- | --- | --- |
| 이미지/아이콘 버튼 접근명 | ✅ | 고객센터/직통연결/뒤로 `aria-label`, 장식 아이콘 `aria-hidden` |
| 색 단독 의존 금지 | ✅ | 상태=색+텍스트/배지(Valid/Expired, Outside business hours) |
| 텍스트 대비 ≥ 4.5:1 | ✅ | primary #0A4DA2 on #fff ≈ 8.6:1, 본문 #1A1F2B |
| 터치 타깃 ≥ 44px | ✅ | `.iconbtn/.callbtn/.btn/.listitem` min 44~48px |
| 키보드 도달·조작 | ✅ | 모든 액션이 `<button>/<a>`, 네이티브 포커스 |
| 포커스 가시성 | ✅ | `:focus-visible` outline(버튼/리스트/콜) |
| 화면 전환 안내 | ✅ | 전환 시 대상 화면에 focus 이동(tabindex -1) |
| 상태 변화 안내 | ✅ | 토스트 `role="status" aria-live="polite"`, 인증오류 `role="alert"` |
| 모션 저감 | ✅ | `@media (prefers-reduced-motion:reduce)` 애니메이션 제거 |
| 직통연결 대안 | ✅ | 통화 불가 시 번호 복사 안내, 운영시간 외 이메일 대안 |

## 잔여 권고(개발 단계 이관)
- 탭(보관함) 키보드 좌우 이동 패턴(roving tabindex)은 실구현 시 적용 권고.
- 다국어 적용 시 `lang` 속성 동적 변경 + 번역 리소스 연결 필요.
- 실제 스크린리더(NVDA/VoiceOver) 수동 테스트는 개발 빌드에서 수행 권고.
