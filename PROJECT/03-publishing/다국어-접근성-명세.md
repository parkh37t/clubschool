## 2. `lang` 속성 동적 변경 시나리오

### 2-1. 전체 문서 언어 변경

언어 전환 시 `<html>` 요소의 `lang` 속성을 교체한다.

```js
// 언어 전환 핸들러 — 기존 case "lang" 교체
case "lang":
  switchLanguage(selectedLocale); // 예: "zh", "vi", "en"
  break;

function switchLanguage(locale) {
  document.documentElement.lang = locale;       // <html lang="zh">
  document.documentElement.dir = locale === "ar" ? "rtl" : "ltr"; // RTL 분기
  applyTranslations(locale);                    // 번역 리소스 적용
  announceLangChange(locale);                   // 스크린리더 재공지
  manageFocusAfterLangSwitch();                 // 포커스 관리
}
```

**WCAG 근거**: SC 3.1.1 Language of Page (A), SC 3.1.2 Language of Parts (AA)

### 2-2. 부분 콘텐츠 `lang` 속성 지정

화면 전체가 전환되지 않는 경우, 특정 언어로 고정된 콘텐츠는 해당 요소에 `lang`을 명시한다.

| 위치 | 현재 마크업 | 명세 |
| --- | --- | --- |
| S8 고객센터 — "中文" | `<strong>中文</strong>` | `<strong lang="zh">中文</strong>` |
| S8 고객센터 — "Tiếng Việt" | `<strong>Tiếng Việt</strong>` | `<strong lang="vi">Tiếng Việt</strong>` |
| S8 고객센터 — "English" | `<strong>English</strong>` | `lang` 불필요(UI 언어와 동일할 경우) / UI가 비영어일 때 `<strong lang="en">English</strong>` |
| 브랜드명 "i-ONE Bank Global" | `<span class="brand">` | `<span class="brand" lang="en">i-ONE Bank Global</span>` — 고유명사이므로 UI 언어 무관 영어 고정 |

**WCAG 근거**: SC 3.1.2 Language of Parts (AA) — 스크린리더가 언어별 TTS 엔진을 올바르게 선택하도록 보장.

## 3. 언어 전환 직후 포커스 관리 및 스크린리더 재공지

### 3-1. 포커스 관리 시나리오

| 상황 | 포커스 대상 | 이유 |
| --- | --- | --- |
| 언어 전환 완료 (전체 화면 재렌더) | 현재 화면의 `<section[data-screen].active>` (`tabindex="-1"`) | 기존 `show()` 패턴 재사용, 화면 상단부터 재읽기 |
| 언어 선택 드롭다운 닫힘 (화면 유지) | 언어 전환 버튼 `.lang` 자신 | 드롭다운 닫힘 후 트리거 복귀 — WCAG SC 2.1.2 |
| 언어 선택 드롭다운 닫힘 (일부 콘텐츠 업데이트만) | 업데이트된 콘텐츠 영역 첫 번째 포커스 가능 요소 또는 컨테이너 | 변경 범위만큼만 포커스 이동 |

```js
function manageFocusAfterLangSwitch() {
  var activeScreen = document.querySelector("[data-screen].active");
  if (activeScreen) {
    activeScreen.setAttribute("tabindex", "-1");
    activeScreen.focus({ preventScroll: false });
  }
}
```

### 3-2. 스크린리더 재공지 — aria-live

언어 전환 결과를 스크린리더에 알리기 위해 별도 라이브 리전을 둔다. 기존 토스트(`role="status" aria-live="polite"`)를 재활용한다.

```js
function announceLangChange(locale) {
  var labels = { en: "Language changed to English", zh: "语言已切换为中文", vi: "Đã chuyển sang Tiếng Việt", ar: "تم تغيير اللغة إلى العربية" };
  toast(labels[locale] || "Language changed");
  // 토스트 요소: <div id="toast" role="status" aria-live="polite">
  // polite → 현재 읽기 완료 후 공지. assertive는 사용하지 않음(사용자 흐름 방해 금지)
}
```

**주의**: `aria-live="polite"` 사용. 언어 전환은 긴급 상황이 아니므로 `assertive` 금지.

### 3-3. 읽힘 순서 보장

- 언어 전환 후 화면 `<section>` 에 포커스 이동 → 스크린리더가 `aria-label` (예: `aria-label="Home"`)을 읽은 후 순서대로 콘텐츠 탐색.
- 동적으로 갱신된 텍스트 노드만 교체하는 방식(innerHTML 전체 교체 아닌 textContent 교체)을 권장. DOM 구조 유지 시 포커스 이동 없이도 `aria-live` 만으로 충분.
- 번역 적용 함수 내에서 요소 교체 순서: ① 헤더/브랜드 → ② 현재 화면 제목(`data-title`) → ③ 본문 텍스트 → ④ CTA 버튼 레이블 → ⑤ ARIA 레이블 일괄 갱신.

## 4. 숫자 / 전화번호 / 날짜 로캘 처리

### 4-1. 전화번호 표기

| 항목 | 현재 | 명세 |
| --- | --- | --- |
| 표시 형식 | `+82-2-1588-9999` | 로캘 무관 E.164 기반 표기 유지(국제 사용자 대상이므로 국가코드 포함 형식이 적합) |
| `href` 값 | `tel:+82215889999` | 변경 없음 — `tel:` URI는 로캘 무관 |
| 가시 텍스트 읽힘 | 스크린리더가 개별 숫자로 읽을 수 있음 | `aria-label`로 읽힘 방식 명시 (아래 참조) |

#### 전화번호 `aria-label` 다국어화 명세

```html
<!-- 현재 -->
<a class="callbtn" href="tel:+82215889999" aria-label="Call English support">

<!-- 개선: UI 언어별 레이블 동적 교체 -->
<!-- en -->  aria-label="Call English support line, +82 2 1588 9999"
<!-- zh -->  aria-label="拨打英文客服热线，+82 2 1588 9999"
<!-- vi -->  aria-label="Gọi đường dây hỗ trợ tiếng Anh, +82 2 1588 9999"
```

번호 읽힘 보조: 전화번호 텍스트 링크(`<a class="num">`)에 `aria-label`을 추가하거나, 숫자 사이 구분자를 스크린리더가 "대시"로 읽지 않도록 `aria-label`로 숫자 그룹을 명시한다.

```html
<a class="num" href="tel:+82215889999"
   aria-label="Plus 82 2 1588 9999">+82-2-1588-9999</a>
```

> [추측] 언어별 숫자 그룹 읽힘 관례가 다를 수 있음(예: 중국어 TTS는 자릿수 읽힘이 다름). 실기기 스크린리더 테스트 필요.

### 4-2. 날짜 표기

| 위치 | 현재 출력 | 명세 |
| --- | --- | --- |
| S5 완료 화면 `s5-date` | `today()` → `"2026-06-21"` (ISO 8601, 하드코딩) | `Intl.DateTimeFormat` 으로 로캘별 포맷 변환 |
| S6 보관함 발급일 `Issued YYYY-MM-DD` | 동일 | 동일 |
| S7 상세 `s7-date` | 동일 | 동일 |

```js
function formatDate(isoString, locale) {
  // locale: "en", "zh", "vi" 등 BCP 47 태그
  return new Intl.DateTimeFormat(locale, { year: "numeric", month: "long", day: "numeric" }).format(new Date(isoString));
  // en → "June 21, 2026"
  // zh → "2026年6月21日"
  // vi → "21 tháng 6, 2026"
}
```

`today()` 함수 반환값을 ISO 문자열로 유지하고, 표시 시점에 `formatDate(isoStr, currentLocale)` 로 변환한다. DOM 저장값은 ISO 유지(데이터와 표현 분리).

### 4-3. 금액 표기

S0 홈 화면 잔액 `₩ 1,250,000`은 현재 하드코딩이나, 실제 구현 시:

```js
new Intl.NumberFormat(locale, { style: "currency", currency: "KRW" }).format(1250000);
// en → "₩1,250,000"
// zh → "₩1,250,000"  (로캘 동일, 통화 기호는 KRW 고정)
```

> 통화 단위는 KRW 고정이므로 로캘에 따른 통화 변환은 해당 없음. 숫자 구분자(천 단위 쉼표) 형식만 로캘 적용.

## 5. RTL(아랍어 등) 가능성 점검 및 레이아웃 영향

> 현재 아랍어는 미확정 요구사항. 아래는 [추측] 기반 사전 대응 점검이다.

### 5-1. CSS 논리 속성 적용 점검

| 현재 사용 물리 속성 | RTL 대응 논리 속성 | 영향도 |
| --- | --- | --- |
| `margin-left`, `padding-left` | `margin-inline-start`, `padding-inline-start` | [추측] 레이아웃 반전 필요 |
| `text-align: left` | `text-align: start` | [추측] 아이콘+텍스트 행 정렬 반전 |
| `direction: ltr` (묵시적) | `dir="rtl"` 동적 설정 | `document.documentElement.dir = "rtl"` |
| `.chev` 화살표 `›` | CSS `transform: scaleX(-1)` 또는 `‹` 교체 | [추측] |
| 탭 순서 (S6 탭바) | 시각적 우→좌, 논리적 우→좌 일치 필요 | [추측] |

### 5-2. 스크린리더 읽힘 순서 (RTL)

- `dir="rtl"` 설정 시 스크린리더는 DOM 순서(코드 순서)를 기준으로 읽으며, 시각적 순서와 DOM 순서가 일치해야 한다(WCAG SC 1.3.2, SC 2.4.3).
- 아이콘 → 텍스트 순서의 DOM 구조가 RTL 시각과 역전되지 않도록 Flexbox `flex-direction: row-reverse` 대신 논리 속성(`flex-direction: row` + `direction: rtl`) 사용을 권장한다. [추측]

### 5-3. 미확정 사항 (개발 단계 협의 필요)

- [ ] [추측] 아랍어 글꼴 스택 지정 필요 여부
- [ ] [추측] 아랍어 숫자(٠١٢) vs 서양 숫자(0 1 2) 중 어느 쪽 표기를 사용할지
- [ ] [추측] 운영시간 표기 방향(오른쪽 정렬 → 왼쪽 정렬 전환)

## 6. `prefers-reduced-motion` 유지 확인

기존 `접근성체크.md`에서 통과한 항목이나, 언어 전환 애니메이션이 추가될 경우 동일 원칙을 적용한다.

```css
/* 언어 전환 시 화면 전체 페이드 효과를 추가할 경우 */
.screen.lang-transition {
  animation: fadeIn 0.2s ease;
}

@media (prefers-reduced-motion: reduce) {
  .screen.lang-transition {
    animation: none; /* 모션 제거, 즉시 표시 */
  }
}
```

### 체크리스트

| 항목 | 상태 |
| --- | --- |
| 언어 전환 트리거 애니메이션에 `prefers-reduced-motion` 분기 | 신규 추가 시 필수 |
| 기존 화면 전환 슬라이드 모션 분기 | 기존 통과(재확인 불필요) |
| 토스트 페이드 인/아웃 분기 | 기존 통과(재확인 불필요) |
| 드롭다운 열림 애니메이션 (언어 선택 목록) | 신규 구현 시 분기 필요 |

## 7. 키보드 동선 영향

### 7-1. 언어 선택 드롭다운(Listbox) 키보드 패턴

현재 언어 버튼은 `aria-haspopup="listbox"` 만 선언되어 있고 실제 listbox가 없다. 구현 시 키보드 동선:

| 키 | 동작 |
| --- | --- |
| `Enter` / `Space` | 언어 목록 열기 |
| `↑` / `↓` | 언어 항목 탐색 |
| `Enter` | 언어 선택 및 닫기 → 버튼으로 포커스 복귀 |
| `Esc` | 닫기 → 버튼으로 포커스 복귀 |
| `Tab` (열린 상태) | 목록 닫기 → 다음 포커스 대상으로 이동 |

```html
<!-- 권장 마크업 구조 -->
<button class="lang" data-action="lang"
        aria-haspopup="listbox"
        aria-expanded="false"
        aria-controls="lang-list"
        aria-label="언어 선택, 현재: English">EN ▾</button>

<ul role="listbox" id="lang-list" aria-label="언어 선택" hidden>
  <li role="option" aria-selected="true" data-locale="en">English</li>
  <li role="option" aria-selected="false" data-locale="zh" lang="zh">中文</li>
  <li role="option" aria-selected="false" data-locale="vi" lang="vi">Tiếng Việt</li>
</ul>
```

> `aria-expanded` 상태는 열림/닫힘 시 동적으로 `"true"`/`"false"` 로 전환.

### 7-2. 언어 전환 후 탭 순서 보장

- 언어 전환으로 DOM 텍스트가 갱신되어도 탭 순서는 변경하지 않는다.
- RTL 전환 시 CSS 논리 속성을 사용하면 시각적 순서가 반전되어도 DOM 순서(탭 순서)를 유지할 수 있다. [추측]
- S6 탭바의 roving tabindex 패턴(기존 잔여 권고)은 언어 전환과 무관하게 독립 구현.

### 7-3. 포커스 트랩 (언어 드롭다운)

드롭다운이 열린 동안 `Tab`이 목록 밖으로 나가지 않도록 포커스 트랩을 적용하되, `Esc`로 즉시 해제 가능하게 한다. 단순 listbox의 경우 포커스 트랩보다 `Esc` 닫기 + 포커스 복귀 패턴이 적합하다.

## 8. ARIA 역할·라벨 다국어화 대응 체크리스트

| 요소 | 현재 `aria-label` | 다국어화 필요 | 구현 방법 |
| --- | --- | --- | --- |
| 고객센터 버튼 `aria-label="Customer center"` | 영어 고정 | 필요 | 번역 리소스에서 키 조회 후 `setAttribute` |
| 뒤로 버튼 `aria-label="Go back"` | 영어 고정 | 필요 | 동일 |
| 영어 직통전화 `aria-label="Call English support"` | 영어 고정 | 필요(지원 언어명 번역) | 지원 언어명은 해당 언어로 고정(예: 中文, English), 액션 동사만 UI 언어로 |
| S6 탭 그룹 `aria-label="Certificate folders"` | 영어 고정 | 필요 | 번역 리소스 |
| S4 인증 그룹 `aria-label="Authentication method"` | 영어 고정 | 필요 | 번역 리소스 |
| `role="application"` `aria-label="i-ONE Bank Global prototype"` | 고유명사 포함 | 부분 필요 | "prototype" 부분만 번역, 브랜드명은 `lang="en"` 유지 |
| 인증오류 `role="alert"` 텍스트 | 영어 고정 | 필요 | `textContent` 번역 |
| 토스트 `role="status"` 텍스트 | 영어 고정 | 필요 | 언어 전환 공지 포함 모든 토스트 번역 |
