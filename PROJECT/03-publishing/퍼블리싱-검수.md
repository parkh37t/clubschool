# 퍼블리싱 검수표 — 전자지갑 & 고객센터 프로토타입

> 담당: 표준수(기본 퍼블리셔) · 산출물: `prototype/index.html`, `styles.css`, `app.js`
> 실행: 브라우저로 `prototype/index.html` 열기(외부 의존성 없음, file:// 동작).

## 구현 범위
- 8개 화면(S0~S8) 단일 HTML, JS 라우팅으로 화면 전환.
- 거래 플로우(전자지갑 발급 → 신청가능목록 → 신청·인증 → 완료 → 보관함 → 상세).
- 고객센터 언어별 직통연결(`tel:`).
- 상태: 로딩(스켈레톤)·빈(보관함/발급가능)·오류(기관 점검)·예외(인증 실패/미보유/운영시간 외).
