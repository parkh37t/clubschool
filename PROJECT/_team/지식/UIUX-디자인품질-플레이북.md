# UIUX 디자인 품질 플레이북 — 럭셔리 호텔 (팀 학습)

> 위치: 공유 지식(과제 무관 재사용) · 트리거: 호텔/럭셔리/예약 UIUX 시안
> 출처: 2025 호텔 웹 디자인 벤치마킹(아래) + 와일리 품질 기준. 시안 제작 전 본 문서를 적용한다.

## 1. 럭셔리 호텔 웹 핵심 패턴 (벤치마킹)
1. **오픈 부킹 패널** — 홈 상단에 날짜 프리필된 예약 위젯 노출 → 부킹엔진 클릭률 +약 30%.
2. **헤더 상시 Book Now** — 모든 페이지 스크롤 없이 노출.
3. **시네마틱 비주얼** — 풀스크린 이미지/영상, 인터랙티브 갤러리. "방"이 아니라 "분위기/감정"을 판다.
4. **타이포** — 우아한 **세리프 헤드라인** + 깔끔한 **산세리프 본문**.
5. **미니멀·명료** — 군더더기 제거, 스토리텔링·신뢰(최저가 보장·리뷰).
6. **모바일 퍼스트·속도** — 3초 내 로딩(53% 이탈), 터치 최적.
7. **개인화** — 행동 기반 추천 패키지·회원가.

## 2. 와일리 품질 기준 (시안 체크리스트)
- [ ] 히어로: 풀블리드 **실사 이미지** + 하단 그라데이션 오버레이 + 대형 세리프 헤드라인
- [ ] 예약 위젯: 아이콘+라벨, 구분선, **골드 CTA**, 프리필, hover 상태
- [ ] 카드: 실사 이미지 + 가격 위계(정가 취소선·회원가 강조) + 별점(SVG) + hover lift
- [ ] 타이포 스케일: Display 40–64 / H2 20–28 / Body 14–16 / Caption 12, letter-spacing(kicker)
- [ ] 여백: 섹션 패딩 넉넉히(48–80px), 그리드 정렬, 정돈된 리듬
- [ ] 아이콘: **인라인 SVG**(이모지/글자 글리프 금지)
- [ ] 색/대비: 의미 토큰, 절제된 골드 포인트, 다크 히어로 대비 충족
- [ ] 깊이/모션: 단일·절제된 shadow, 0.2s hover transition, prefers-reduced-motion 존중
- [ ] 신뢰 요소: 최저가 보장·리뷰·멤버 혜택 가시화
- [ ] 접근성(KWCAG 2.2): 대비·키보드·대체텍스트·터치 타깃 44px

## 3. 이미지 적용 기법 (이 환경 제약 대응)
- 컨테이너 egress가 외부 이미지 CDN을 차단(403)하나, **딜리버 HTML은 사용자 브라우저에서 로드**되므로
  유효한 이미지 URL 참조는 정상 표시됨.
- **안전 폴백**: `background: linear-gradient(overlay), url(photo) center/cover, linear-gradient(fallback)`
  → 사진 실패 시 **우아한 그라데이션**으로 degrade(깨진 아이콘 방지). 폴백 자체를 럭셔리하게 설계.
- 실 제출본은 발주 제공 이미지/촬영 컷으로 교체(시안은 방향 제시).

## 4. 안티패턴 (직전 시안의 문제)
- 플랫 그라데이션 박스를 이미지 대용으로 사용 → "와이어프레임"처럼 보임.
- 이모지/글자 글리프 아이콘, 좁은 여백, 약한 타이포 위계 → 저급 인상.
