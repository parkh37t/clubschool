# 규칙: 문서화

## 언어
- 모든 문서, 주석, 커밋 메시지는 **한국어 우선**으로 작성합니다. (코드 식별자는 영어)

## 주석
- "무엇"이 아니라 "왜"를 설명합니다. 코드로 자명한 내용은 주석을 달지 않습니다.
- 도메인 용어(맨먼스, 가동률, 유휴비용 등)에는 단위/계산 기준을 한 줄로 명시합니다.
  - 예: `utilizationRate: number; // 현재 가동률 (%)`
- 주석 밀도는 주변 코드와 일치시킵니다. 기존 파일의 톤을 따릅니다.

## 커밋 메시지
- 형식: `<타입>: <한국어 요약>` (예: `Fix: 가동률 계산 반올림 오차 수정`)
- 타입: `Feat`, `Fix`, `Refactor`, `Docs`, `Style`, `Test`, `Chore`
- 본문에는 변경 이유와 영향 범위를 적습니다. 무엇을 했는지보다 왜 했는지 중심.

## 문서 산출물
- 화면/기능을 추가하면 README의 "주요 기능" 또는 관련 문서를 갱신합니다.
- 새 도메인 개념은 `CLAUDE.md`의 "핵심 도메인 개념"에 추가합니다.
- 배포 관련 변경은 `DEPLOY.md` / `QUICK_DEPLOY.md`에 반영합니다.

## 금지
- 모델 식별자, 내부 세션 URL 등을 코드/문서/커밋에 남기지 않습니다.
- 더 이상 사실이 아닌 문서를 방치하지 않습니다. 코드와 문서가 충돌하면 먼저 알립니다.
