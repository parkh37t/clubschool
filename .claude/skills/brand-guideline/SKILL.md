# 브랜드 가이드(BX) 산출

일관된 브랜드 정체성과 비주얼 시스템을 문서화합니다.

## 절차
1. **브랜드 전략**: 미션/가치/타깃과 전달할 핵심 감정을 정의.
2. **콘셉트 키워드**: 3~5개 키워드로 브랜드 언어를 압축.
3. **비주얼 시스템**: 컬러(HEX + 토큰 매핑), 타이포 위계, 로고 사용 규칙, 그래픽 모티프.
4. **톤앤매너**: 보이스 가이드와 do/don't 예시.
5. **적용 가이드**: 제품 UI 토큰(차도안)·마케팅 비주얼(홍보라)과의 연결.

## 산출물 포맷
```md
## 브랜드 가이드: <브랜드명>
| 항목 | 내용 |
| --- | --- |
| 미션/가치 | |
| 콘셉트 키워드 | |
| 컬러 (HEX / 토큰) | |
| 타이포 위계 | |
| 로고 사용 규칙 | do/don't |
| 그래픽 모티프 | |
| 톤앤매너(보이스) | do/don't |
```

## 원칙
- 컬러 대비는 접근성(WCAG AA) 충족. 제품 디자인 토큰과 매핑 가능하게 정의.
- 추상 수식어 대신 구체적 예시(do/don't)로 규칙을 제시.
- `design-system-build`(차도안)·`landing-copywriting`(홍보라)으로 이어집니다.
- 결과는 한국어로 작성.
