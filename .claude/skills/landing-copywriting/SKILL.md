# 랜딩 · 캠페인 카피라이팅

타깃에게 가치를 전달하고 전환을 만드는 카피를 작성합니다.

## 절차
1. **타깃·맥락 정의**: 세그먼트, 진입 채널, 인지 단계(문제 인지/대안 비교 등)를 정리.
2. **가치 번역**: 기능 → 사용자 이점("그래서 무엇이 좋아지는가")으로 변환.
3. **메시지 위계 구성**:
   - 헤드라인(핵심 가치) → 서브헤드(보강) → 본문(근거/사회적 증거) → CTA.
4. **섹션 카피**: 히어로/문제/해결/기능/증거/FAQ/CTA 섹션별 카피 작성.
5. **CTA 설계**: 행동 동사 기반의 명확한 1차 CTA + 보조 CTA.
6. **SEO 기본**: 페이지 타이틀/메타 디스크립션/핵심 키워드 반영.

## 산출물 포맷
```md

| CTA | | |

## SEO
- title / meta / 키워드:
```

## 원칙
- 실제 구현된 가치만 약속(과장 금지). 한 섹션 = 한 메시지.
- 브랜드 톤(`brand-guideline`/오색감)과 일치. 성과 기준은 `kpi-event-tracking`(고지표)과 연결.
- 결과는 한국어로 작성.
