# IA / User Flow 설계

제품 구조와 사용자 동선을 설계해 화면 목록으로 연결합니다.

## 절차
1. **사용자/목표 정의**: 주요 사용자와 그들이 끝내야 할 과업(Job)을 정리.
2. **IA 설계**: 콘텐츠/기능을 그룹핑해 내비게이션 계층을 만듭니다.
   - 이 앱은 `VIEW_NAMES` 기반 단일 스위치 라우팅(`ViewRenderer`)이므로, IA 노드는
     뷰 키 후보와 1:1로 매핑되게 설계.
3. **User Flow**: 핵심 과업별 시작→액션→결과를 그리고 분기/예외를 표기.
4. **화면 목록 도출**: 플로우의 각 노드를 화면으로 환산, 진입 경로를 명시.
5. **상태 정의**: 화면마다 빈/로딩/오류/권한없음 상태를 표기.

## 산출물 포맷
```md
## IA
- (트리 형태) 1차 메뉴 > 2차 > 화면(view 키)

## User Flow: <과업명>
시작 → [액션] → [분기?] → 결과
- 예외:

## 화면 목록
| 화면 | view 키 후보 | 진입 경로 | 필요 데이터 | 상태 |
| --- | --- | --- | --- | --- |
```

## 원칙
- 한 과업이 몇 번의 화면 전환으로 끝나는지(깊이)를 점검해 단순화합니다.
- 모든 화면에 빈/오류/로딩을 정의(행복 경로만 X).
- 결과는 한국어로 작성하고 `service-planning`(화면설계서)으로 이어집니다.
