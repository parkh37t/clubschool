# 제안서 작성

수주를 위한 설득력 있는 제안서를 작성합니다.

## 구성 (표준 목차)
1. **프로젝트 이해**: 발주처 목표를 우리 언어로 재서술(이해도 증명).
2. **접근 전략**: 어떻게 풀 것인가, 차별화 포인트(승부수).
3. **범위**: 포함 / 제외를 명확히. 단계별 산출물.
4. **추진 일정**: 마일스톤·의존성(`kim-sales-support`의 일정 활용).
5. **투입 계획**: 그룹별(planning/design/publishing/management/executive) 인력·맨먼스.
6. **견적**: 맨먼스 × hourlyRate 기반 산정, 가정·제외 명시.
7. **레퍼런스/리스크 관리**: 사례, 리스크와 완화책.

## 작성 원칙
- 발주처의 평가기준(`rfp-analysis` 결과)에 맞춰 강조점을 배치합니다.
- 실제로 할 수 있는 것만 약속합니다(과약속 금지).
- 모든 숫자에 단위·근거. 가정은 "가정"으로 명시.
- 차별점은 추상적 수식어가 아니라 구체적 근거로 제시합니다.
- 결과는 한국어로 작성합니다.

## 연계
- 입력: `rfp-analysis` 산출물, `kim-sales-support`의 견적/일정.
- 출력: 수주 확정 시 `jung-wooseon-po`에게 핸드오프(`.claude/rules/handoff.md`).
