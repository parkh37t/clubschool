# 품질 게이트

머지/푸시 직전 통과해야 하는 최종 점검입니다. (`.claude/rules/quality-check.md` 기준)

## 1) 자동 검사 (전부 통과 필수)
```bash
npm run type-check   # 타입 오류 0
npm run lint         # 경고 포함 0 (--max-warnings 0)
npm run build        # 프로덕션 빌드 성공
```
하나라도 실패하면 머지 금지. 실패 출력은 그대로 보고합니다.

## 2) 도메인 정합성 체크리스트
- [ ] 도메인 데이터 접근이 `useDataStore`를 경유하는가(localStorage 직접 접근 X)?
- [ ] 신규 타입/필드가 `types/index.ts`에 정의되었는가?
- [ ] 새 화면이 `VIEW_NAMES` → `ViewRenderer` → 네비게이션까지 연결되었는가?
- [ ] 연관 데이터 동기화(allocation/manmonth 재계산)가 유지되는가?
- [ ] 맨먼스(0~1)·가동률(0~100) clamp가 지켜지는가?

## 3) UI/디자인
- [ ] 디자인 토큰 사용(하드코딩 색 없음), 다크 모드 정상.
- [ ] 모바일/데스크톱 양쪽 동작. (필요 시 `ui-review` 스킬 병행)

## 4) 보고
- 통과/실패/건너뜀을 분명히 보고합니다(숨기지 않음).
- 회귀 위험 변경은 영향 범위를 함께 적습니다.
- 파괴적/되돌릴 수 없는 작업은 실행 전 확인을 받습니다.

결과는 한국어로 작성합니다.
