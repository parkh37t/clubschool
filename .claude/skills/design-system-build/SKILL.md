# 디자인 시스템 구축

토큰과 컴포넌트로 일관된 디자인 시스템을 구축·확장합니다.

## 절차
1. **토큰 정의**: 색/타이포/간격/반경/그림자를 의미 토큰으로 정의합니다.
   - 이 프로젝트는 CSS 변수 → `tailwind.config.js` 매핑 구조. 색은 의미 토큰
     (`primary`, `muted`, `destructive`, `chart-1~5` 등)으로 정의해 다크 모드 자동 대응.
2. **컴포넌트 인벤토리**: 필요한 컴포넌트를 나열하고 `components/ui/`의 기존 shadcn/ui
     컴포넌트와 매칭(중복 신규 제작 금지).
3. **컴포넌트 명세**: 각 컴포넌트의 variant·size·state(기본/호버/포커스/비활성/로딩/오류)
     를 정의.
4. **사용 규칙**: do/don't, 조합 패턴, 간격 스케일 사용법을 정리.
5. **확장 가이드**: 새 토큰/컴포넌트 추가 시 절차와 네이밍 규칙.

## 산출물 포맷
```md
## 토큰
| 그룹 | 토큰명 | 값/매핑 | 용도 |
| --- | --- | --- | --- |

## 컴포넌트 명세: <이름>
| 항목 | 내용 |
| --- | --- |
| variant / size | |
| state | 기본/호버/포커스/비활성/로딩/오류 |
| 사용 토큰 | |
| do / don't | |
```

## 원칙
- 하드코딩 색/간격 금지(토큰만). 클래스 병합은 `cn()` 사용.
- 같은 의미의 상태는 같은 토큰. 다크 모드에서 깨지지 않게 의미 토큰만 사용.
- `oh-brand-designer`의 브랜드 토큰과 1:1 정렬. 결과는 한국어로 작성.
