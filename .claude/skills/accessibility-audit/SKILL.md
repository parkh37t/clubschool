# 접근성 점검 (WCAG)

화면/컴포넌트의 접근성을 표준 기준으로 점검하고 개선안을 도출합니다.

## 체크리스트
### 인지(Perceivable)
- [ ] 이미지 `alt`, 아이콘 버튼에 접근명(aria-label) 제공
- [ ] 텍스트 대비 ≥ 4.5:1(본문) / 3:1(큰 텍스트·UI 요소)
- [ ] 색만으로 정보 전달하지 않음(상태=색+아이콘/텍스트)

### 운용(Operable)
- [ ] 키보드만으로 모든 기능 도달·조작 가능, 포커스 순서가 논리적
- [ ] 포커스 가시성(focus ring) 유지, 포커스 트랩(모달) 처리
- [ ] `prefers-reduced-motion` 존중, 자동재생/깜빡임 제어

### 이해(Understandable)
- [ ] 폼 라벨·에러 메시지 연결(`label`/`aria-describedby`)
- [ ] 상태 변화(로딩/완료/오류)를 `aria-live`로 안내

### 견고(Robust)
- [ ] 시맨틱 태그/역할(role) 사용, 중복 id 없음
- [ ] 커스텀 위젯에 적절한 ARIA 패턴 적용

## 산출물 포맷
```md
## 접근성 점검: <화면/컴포넌트>
| 기준 | 결과(통과/실패) | 위치(파일:라인) | 개선안 | 심각도 |
| --- | --- | --- | --- | --- |
```

## 원칙
- 심각도(blocker/major/minor)로 분류하고 각 항목에 구체적 수정안을 답니다.
- 통과 시 "접근성 점검 통과"로 명시. 결과는 한국어로 작성.
- 입력: `pyo-publisher` 마크업 / `cha-ui-designer` 상태별 UI. 출력: `gu-frontend-developer`
  구현 반영.
