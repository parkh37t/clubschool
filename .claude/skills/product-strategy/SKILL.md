# 제품 전략

제품의 방향과 우선순위를 정의합니다.

## 절차
1. **비전/문제 정의**: 누구의 어떤 문제를 푸는가. 이 제품은 "조직의 인력 가동을
   가시화하고 투입 의사결정을 빠르게" 하는 것이 핵심 가치입니다.
2. **성공 지표(KPI)**: 측정 가능한 목표를 정의합니다.
   - 예: 가동률 가시성, 유휴비용 절감, 프로젝트 승인 리드타임 단축.
3. **사용자/시나리오**: 본부장(전사 모니터링), 사업관리팀(투입 조정), 팀 리더 등.
4. **기능 우선순위**: 가치 대비 비용으로 정렬(예: RICE/Impact-Effort).
5. **로드맵**: 단계별(MVP → 확장)로 묶고 의존성을 명시합니다.

## 우선순위 판단
- "더 많이"가 아니라 "가장 중요한 것". 범위 확장은 비용을 명시하고 결정합니다.
- 기존 기능(대시보드/분석/구성원/프로젝트 워크플로우)을 강화하는지, 새 축을 여는지 구분.

## 산출물 포맷
```md
# 제품 전략
## 비전 / 해결할 문제
## 성공 지표(KPI)
## 우선순위 백로그 (가치 / 비용 / 근거)
## 로드맵 (단계 / 의존성)
## 트레이드오프 결정
```

## 원칙
- 결정은 권고안 + 근거로 제시합니다. 결과는 한국어로 작성합니다.
- 다음 단계는 `service-planning`(기획)으로 인계합니다.
